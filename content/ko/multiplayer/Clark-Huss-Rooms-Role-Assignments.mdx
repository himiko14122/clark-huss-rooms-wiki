Clark Huss rooms에서의 역할 배정은 탐색, 위협 감지, 손전등 관리의 인지적 부담을 분대원들에게 분산시킵니다. 역할이 배정되지 않으면 모든 플레이어가 선두를 자처하고, 아무도 듣지 않으며, 첫 Clark 조우에서 분대가 분열됩니다. 역할이 배정되면 각 플레이어는 자신의 책임을 알고 자신의 구체적인 공헌에 집중할 수 있습니다.

이 가이드는 세 가지 핵심 역할을 자세히 다루고, 각 역할의 스킬 요구사항, 피로 방지를 위한 로테이션 시스템, 분대 구성 전략을 설명합니다. 또한 플레이어 강점에 맞춰 역할을 배정하는 방법, 역할 실패를 처리하는 방법, 그리고 언제 책임을 교체할지 배우게 됩니다.

## 세 가지 핵심 역할

모든 조정된 분대는 세 가지 핵심 역할을 사용합니다. 역할은 선두(탐색), 후위 경비(오디오 모니터링), 조명 관리자(손전등 제어)입니다.

### **역할 정의:**

| 역할 | 주요 기능 | 부가 기능 |
|------|------------------|--------------------|
| 선두 | 탐색 및 경로 선택 | 공간 기억 관리 |
| 후위 경비 | Clark 오디오 모니터링 | 분대 분리 방지 |
| 조명 관리자 | 손전등 타이밍 및 배터리 | 시각적 조정 |

이 역할들은 런 중간에 서로 호환되지 않습니다. 각각은 다른 스킬과 사고방식을 요구합니다.

## 선두 역할 상세

선두는 분대 맨 앞에서 걸으며 어느 복도로 들어갈지 선택합니다. 선두의 결정은 시간이 지남에 따라 누적되며, 잘못된 결정은 분대의 시간과 배터리를 소모시킵니다.

### **선두 책임:**

| 책임 | 설명 |
|----------------|-------------|
| 경로 선택 | 분기점에서 가지 선택 |
| 공간 매핑 | 복도의 정신적 지도 구축 |
| 분대 소통 | 다가오는 결정 알림 |
| 페이스 설정 | 오디오 모니터링을 위한 걷는 속도 조절 |
| 탈출 경로 계획 | 후퇴 경로 사전 파악 |

### **선두 스킬 요구사항:**

| 스킬 | 중요도 |
|-------|------------|
| 공간 기억 | 매우 높음 |
| 결정 확신 | 높음 |
| 인내심 | 높음 |
| 경로 효율성 | 높음 |
| 분대 관리 | 중간 |

선두 역할은 탐색을 즐기고 시각-공간 기억력이 강한 플레이어에게 적합합니다.

## 후위 경비 역할 상세

후위 경비는 분대 맨 뒤에서 걸으며 Clark 오디오 신호를 모니터링합니다. 후위 경비의 콜아웃은 분대가 대비할 수 있도록 조기 경고를 제공합니다.

### **후위 경비 책임:**

| 책임 | 설명 |
|----------------|-------------|
| 오디오 모니터링 | Clark 오디오 신호 청취 |
| 콜아웃 실행 | Clark 위치 및 거리 알림 |
| 분리 방지 | 분대 간격 모니터링 |
| 위협 평가 | Clark의 행동 상태 판단 |
| 추격 조정 | 활성 추격 중 콜아웃 |

**후위 경비 스킬 요구사항:**

| 스킬 | 중요도 |
|-------|------------|
| 오디오 해석 | 매우 높음 |
| 압박 속 냉정함 | 높음 |
| 콜아웃 속도 | 높음 |
| 공간 인식 | 높음 |
| 인내심 | 중간 |

후위 경비 역할은 오디오 해석 능력이 뛰어나고 추격 중에도 냉정함을 유지할 수 있는 플레이어에게 적합합니다.

## 조명 관리자 역할 상세

조명 관리자는 분대 중간에서 걸으며 손전등 타이밍을 제어합니다. 조명 관리자의 클릭은 배터리를 낭비하지 않고 시각적 확인 창구를 제공합니다.

**조명 관리자 책임:**

| 책임 | 설명 |
|----------------|-------------|
| 손전등 타이밍 | 결정 지점에서 클릭 |
| 배터리 관리 | 남은 용량 추적 |
| 분대 조정 | 대형에 맞춘 클릭 타이밍 |
| 임계값 결정 | 배터리에 따른 모드 전환 |
| 로테이션 관리 | 필요 시 역할 전달 |

**조명 관리자 스킬 요구사항:**

| 스킬 | 중요도 |
|-------|------------|
| 클릭 규율 | 매우 높음 |
| 타이밍 정확도 | 높음 |
| 배터리 인식 | 높음 |
| 인내심 | 중간 |
| 분대 인식 | 중간 |

조명 관리자 역할은 자기 규율이 강하고 지속적이며 신중한 행동을 위한 인내심이 있는 플레이어에게 적합합니다.

## 플레이어 강점에 역할 맞추기

효과적인 역할 배정은 각 역할을 플레이어 강점에 맞춥니다. 아래 매칭 행렬은 분대가 역할을 배정하는 데 도움을 줍니다.

**플레이어 강점과 역할 매핑:**

| 플레이어 강점 | 최적 역할 |
|-----------------|-----------|
| 강한 공간 기억력 | 선두 |
| 뛰어난 오디오 해석력 | 후위 경비 |
| 인내심 있고 규율적 | 조명 관리자 |
| 압박 속 냉정함 | 후위 경비 또는 선두 |
| 세부 사항에 강함 | 조명 관리자 |
| 순간에 결정적 | 선두 |
| 일관되고 안정적 | 조명 관리자 |

이 매핑은 각 플레이어가 자신의 자연 강점을 활용하는 위치에 배치되도록 보장합니다.

## 역할 로테이션 시스템

지속적인 역할 책임은 피로를 유발합니다. 분대는 오류를 방지하기 위해 역할을 교체해야 합니다. 로테이션 시스템은 분대 규모에 따라 달라집니다.

**로테이션 간격:**

| 분대 규모 | 권장 간격 |
|------------|----------------------|
| 듀오 | 5분 |
| 트리오 | 4분 |
| 콰트로 | 3분 |

로테이션 중 현재 조명 관리자가 다음 플레이어에게 전달하고, 선두와 후위 경비가 서로 자리를 바꾸는 식입니다. 로테이션은 콜아웃으로 알립니다.

## 분대 구성 고려사항

분대 구성은 각 플레이어가 맡는 역할에 영향을 미칩니다. 아래 구성 패턴은 효과가 입증되었습니다.

**효과적인 구성:**

| 구성 | 강점 |
|-------------|-----------|
| 베테랑 3명 | 최대 조정 |
| 베테랑 2명 + 학습자 1명 | 백업이 있는 학습 |
| 혼합 경험 | 다양한 관점 |
| 모두 학습자 | 더 높은 도전, 더 나은 학습 |

구성은 역할 배정에 영향을 미칩니다. 베테랑 쌍이 선두와 후위 경비를 맡고 학습자는 클릭 규율을 발전시키기 위해 조명 관리자가 될 수 있습니다.

## 역할 실패 처리

역할 보유자가 실패할 때, 분대는 빠르게 대응해야 합니다. 아래 실패 처리 프로토콜은 영향을 최소화합니다.

**실패 처리:**

| 실패 | 대응 |
|---------|-----------|
| 선두가 잘못된 길로 감 | 새 선두 지명, 되돌아가기 |
| 후위 경비가 콜아웃 놓침 | 다른 분대원이 보완 |
| 조명 관리자가 클릭 과다 사용 | 다른 플레이어에게 전달 |
| 다중 실패 | 분대 일시 정지, 재집결, 재평가 |

핵심은 빠른 인식과 즉각적인 대응입니다. 지연은 실패를 증폭시킵니다.

## 다중 역할 능력

일부 숙련된 플레이어는 동시에 여러 역할을 수행할 수 있습니다. 이는 한 플레이어가 선두와 조명 관리자를 모두 맡는 듀오 플레이에서 유용합니다.

**다중 역할 구성:**

| 구성 | 결합된 역할 |
|---------------|----------------|
| 듀오: 플레이어 A | 선두 + 조명 관리자 |
| 듀오: 플레이어 B | 후위 경비 + 팔로워 |
| 콰트로: 플레이어 A | 선두 |
| 콰트로: 플레이어 B | 후위 경비 |
| 콰트로: 플레이어 C | 조명 관리자 |
| 콰트로: 플레이어 D | 팔로워 + 백업 |

다중 역할 능력은 연습을 통해 발전합니다. 새로운 플레이어는 먼저 단일 역할에 집중해야 합니다.

## 역할별 준비

각 역할은 런이 시작되기 전에 구체적인 준비가 필요합니다. 아래 준비 단계는 각 플레이어가 준비되도록 보장합니다.

**선두 준비:**

- 로비 맵 간략히 학습
- 유망한 초기 방향 파악
- 탈출 경로 옵션 계획
- 페이스 설정 전략 확인

**후위 경비 준비:**

- 오디오 볼륨 레벨 설정
- 호흡 리듬 식별 연습
- 필요 시 차분한 음성 백업 파악
- 콜아웃 형식 확인

**조명 관리자 준비:**

- 배터리 녹색 확인
- 클릭 패턴 습관 설정
- 로테이션 타이밍 파악
- 모드 전환을 위한 임계값 확인

이 준비는 30초가 걸리며 대부분의 역할 실패를 방지합니다.

## 역할 시너지 패턴

역할 간의 시너지가 분대를 효과적으로 만듭니다. 아래 시너지 패턴은 조정된 플레이에서 관찰됩니다.

**선두-후위 경비 시너지:**

| 패턴 | 효과 |
|---------|--------|
| 후위 경비가 Clark 접근 알림 | 선두가 탈출 경로 선택 |
| 선두가 방향 알림 | 후위 경비가 새로운 각도에서 보고 |
| 둘 다 오디오 관찰 공유 | 포괄적인 위협 그림 |

**조명 관리자-후위 경비 시너지:**

| 패턴 | 효과 |
|---------|--------|
| 후위 경비가 조용한 창 보고 | 조명 관리자가 확인을 위해 클릭 |
| 추격 중 조명 관리자가 절약 | 후위 경비가 오디오에 집중 |
| 둘 다 클릭 주위로 콜아웃 타이밍 | 최대 정보 수집 |

**선두-조명 관리자 시너지:**

| 패턴 | 효과 |
|---------|--------|
| 선두가 분기점 접근 신호 | 조명 관리자가 미리 보기를 위해 클릭 |
| 조명 관리자가 배터리 보고 | 선두가 저조도 지역을 위해 경로 조정 |
| 둘 다 진입 타이밍 조정 | 깔끔한 방 진입 |

강력한 시너지는 같은 분대와 일관된 플레이를 통해 발전합니다.

## 역할 로테이션 모범 사례

역할 로테이션은 매끄럽고 예측 가능해야 합니다. 아래 모범 사례는 로테이션이 조정을 방해하지 않도록 보장합니다.

**로테이션 모범 사례:**

| 사례 | 설명 |
|----------|-------------|
| 로테이션 조기 알림 | "30초 후 조명 전달" |

| 명확한 전달어 | "이제 조명은 당신의 책임입니다" |
| 로테이션 기록 | 새 플레이어가 관찰하며 학습 |

최고의 로테이션은 실행 시 알아챌 수 없습니다.

## 자주 묻는 질문

**가장 중요한 역할은 무엇인가요?**

후위 경비가 가장 중요한데, 그들의 콜아웃이 기습 추적을 방지하기 때문입니다. 뛰어난 오디오 모니터링을 가진 좋은 후위 경비가 중간 정도의 탐색력을 가진 훌륭한 선두보다 우수합니다.

**한 플레이어가 세 가지 역할을 모두 맡을 수 있나요?**

솔로 플레이에서만 가능합니다. 분대에서는 역할 조합이 인지적 과부하를 일으키고 각 역할의 효율성을 감소시킵니다.

**약한 역할을 어떻게 발전시키나요?**

솔로 세션이나 피드백을 줄 수 있는 친구와 함께 약한 역할을 연습하세요. 역할 발전은 의도적인 연습이 필요합니다.

**아무도 특정 역할을 원하지 않으면 어떻게 하나요?**

플레이어 강점을 기반으로 배정하세요. 가장 선호되지 않는 역할은 종종 조명 관리자이지만, 분대 손전등 보존에 중요합니다.

**런 전체 동안 역할이 고정되어야 하나요?**

아니요. 로테이션은 피로를 방지합니다. 고정된 역할은 플레이어가 피로해질 때 오류를 유발합니다.

조정이 필요한 역할 메커니즘에 대한 자세한 내용은 [협동 생존 가이드](/en/multiplayer/co-op-survival-guide/)를 참조하세요. 더 넓은 조정 원칙을 배우려면 [멀티플레이어 조정](/en/guides/multiplayer-coordination/)을 읽어보세요.


**독성 분대원을 어떻게 처리하나요?**

독성 플레이어를 즉시 음소거하세요. 긍정적인 분대원과의 조정에 집중하세요. 전체 분대가 독성이면 로비를 떠나 더 나은 플레이어를 찾으세요. 커뮤니티 채널을 통한 장기적인 분대 구축은 무작위 독성 행동에 노출되는 것을 줄여줍니다.

**내 분대가 전략에 대해 동의하지 않으면 어떻게 하나요?**

게임 전 전략 합의는 런 중 충돌을 방지합니다. 플레이 중 의견 불일치가 발생하면 배정된 선두에게 따르세요. 런 후 토론이 전략 문제를 건설적으로 다룰 수 있습니다. 즉각적인 실패에 직면하지 않는 한 런 중 전략을 변경하지 마세요.

**시간이 지남에 따라 분대로서 어떻게 발전하나요?**

함께 정기적으로 플레이하면 조정 습관이 구축됩니다. 실패한 런을 검토하여 개선 영역을 식별하세요. 추적이나 배터리 관리와 같은 특정 시나리오를 연습하세요. 다재다능한 분대원을 발전시키기 위해 역할을 교체하세요. 여러 세션에 걸쳐 진행 상황을 추적하세요.

**Roblox 음성 채팅과 Discord 중 어느 것을 사용해야 하나요?**

Discord는 일반적으로 Roblox 음성 채팅보다 더 나은 오디오 품질과 더 많은 기능을 제공합니다. Discord는 푸시 투 토크, 노이즈 억제, 채널 분리를 지원합니다. Roblox 음성은 편리하지만 덜 안정적입니다. 대부분의 조정된 분대는 Discord를 선호합니다.

**혼란스러운 로비에서 소통하는 가장 좋은 방법은 무엇인가요?**

표준화된 콜아웃을 사용하고 긴 토론을 피하세요. 푸시 투 토크 규율은 오디오 혼란을 방지합니다. 차분한 음성 지정은 소통을 안정시키는 데 도움이 됩니다. 혼란스러운 플레이어를 음소거하여 분대에 집중하세요.

**다른 시간대에 있는 친구와 플레이할 수 있나요?**

시간대 차이는 일정 유연성이 필요합니다. 일부 분대는 겹치는 시간에 플레이하여 여러 시간대에 걸쳐 조정합니다. 다른 분대는 지역 하위 분대를 형성합니다. 특정 상황에 맞는 것을 찾으세요.

**새로운 분대원과 어떻게 신뢰를 구축하나요?**

신뢰는 일관된 플레이와 안정적인 성과를 통해 구축됩니다. 예정대로 나타나고, 역할을 수행하며, 명확하게 소통하세요. 드라맛을 피하고 게임플레이에 집중하세요. 신뢰는 여러 세션에 걸쳐 자연스럽게 발전합니다.
