Clark Huss rooms는 50인 서버에서 운영되지만, 실제 게임 경험은 그 플레이어 중 몇 명이 함께 협력하느냐에 따라 극적으로 달라집니다. 50인 서버의 솔로 플레이어는 같은 서버의 조직적인 트리오와는 완전히 다른 도전에 직면합니다. 서버 구성 간의 난이도 차이를 이해하면 자신의 실력 수준과 스쿼드 구성에 맞는 서버를 선택하는 데 도움이 됩니다.

이 티어 리스트는 서버 구성을 S(가장 유리)부터 D(가장 어려움)까지 순위를 매기고, 난이도에 영향을 미치는 변수를 설명하며, 최적의 서버 선택을 위한 권장 사항을 제공합니다. 또한 플레이어 실력 분포가 서버 난이도에 어떤 영향을 미치는지, 서버 배정에 영향을 미치는 매치메이킹 요인에 대해서도 배우게 됩니다.

## 서버 구성 티어 프레임워크

각 서버 구성은 세 가지 요인을 기준으로 평가됩니다: 협력 잠재력, Clark 조우 빈도, 자원 가용성. 이 요인들은 다양한 서버 유형의 난이도와 실행 가능성을 결정합니다.

### **서버 구성 요인:**

| 요인 | 설명 |
|--------|-------------|
| 협력 잠재력 | 플레이어가 얼마나 잘 협력할 수 있는지 |
| Clark 조우 빈도 | Clark가 스쿼드를 얼마나 자주 표적으로 삼는지 |
| 자원 가용성 | 손전등 배터리, 스태미나, 공간 |

이 조합은 성공하기 쉬운 S부터 생존하기 가장 어려운 D까지의 티어 순위를 생성합니다.

## Tier S: 조직적 트리오 서버

부분적으로 가득 찬 서버의 조직적 트리오는 스쿼드가 관리 불가능해질 정도의 협력 부담 없이 충분한 역할 커버리지를 갖추고 있으므로 최적의 구성을 나타냅니다.

### **Tier S 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 10 — 25명 활성 (스쿼드 규모 3) |
| 협력 품질 | 높음 (일관된 스쿼드원) |
| Clark 조우율 | 보통 |
| 배터리 관리 | 우수 (3인 로테이션) |
| 평균 생존 시간 | 8 — 12분 |

트리오 구성은 단일 플레이어에게 과도한 부담을 주지 않으면서 Lead, Rear Guard, Light Manager 역할 배분을 허용합니다. 스쿼드는 로테이션을 통해 손전등 사용을 지속하고 런 내내 대형을 유지할 수 있습니다.

## Tier A: 조직적 콰트로 서버

조직적 콰트로는 트리오보다 더 많은 역할 전문화를 제공하지만 추가적인 협력 부담을 수반합니다. 이 구성은 경험 많은 스쿼드에 잘 작동합니다.

### **Tier A 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 15 — 30명 활성 (스쿼드 규모 4) |
| 협력 품질 | 높음 (일관된 스쿼드원) |
| Clark 조우율 | 트리오보다 높음 (더 많은 오디오 소음) |
| 배터리 관리 | 매우 좋음 (4인 로테이션) |
| 평균 생존 시간 | 7 — 11분 |

콰트로는 전문화된 역할(스캐너, 콜아웃 모니터, 탈출 경로 플래너)을 커버할 추가 플레이어를 보유하고 있지만, 4명의 플레이어에서 발생하는 추가 오디오 소음은 Clark의 탐지 확률을 높입니다.

## Tier B: 조직적 듀오 서버

조직적 듀오는 잘 작동하지만 역할 전문화가 부족합니다. 두 플레이어 모두 여러 역할을 커버해야 하므로 인지 부하가 증가합니다.

### **Tier B 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 8 — 20명 활성 (스쿼드 규모 2) |
| 협력 품질 | 높음 (일관된 스쿼드원) |
| Clark 조우율 | 낮음 (2개의 오디오 소스만) |
| 배터리 관리 | 제한적 (2인 로테이션) |
| 평균 생존 시간 | 6 — 10분 |

듀오의 주요 장점은 낮은 오디오 발자국입니다. 두 명의 플레이어가 최소한의 소음을 발생시키므로 Clark 조우가 덜 빈번해집니다. 단점은 배터리 관리가 덜 유연하다는 것입니다.

## Tier B: 부분 서버 솔로

부분 서버(10 — 30명)에서 솔로 플레이는 다른 사람과 협력하지 않고도 탐색할 수 있으며 동시에 주변 플레이어 활동의 이점을 누릴 수 있으므로 독특한 경험을 제공합니다.

**Tier B 솔로 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 10 — 30명 활성, 솔로 플레이어 |
| 협력 품질 | 해당 없음 (솔로) |
| Clark 조우율 | 낮음 |
| 배터리 관리 | 개인 |
| 평균 생존 시간 | 5 — 9분 |

부분 서버 솔로 구성은 협력 부담 없이 오디오 기술을 연습하려는 플레이어에게 적합합니다. 스쿼드가 없다는 것은 역할 분배가 없다는 뜻이지만, 동시에 협력 복잡성도 없다는 뜻입니다.

## Tier C: 풀 로비 (50명)

가득 찬 50인 서버는 너무 많은 오디오 소스가 Clark의 관심을 놓고 경쟁하고 조직적인 움직임을 방해하기 때문에 조직적 플레이에 가장 나쁜 구성입니다.

**Tier C 풀 로비 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 50명 활성 |
| 협력 품질 | 나쁨 (랜덤 공개) |
| Clark 조우율 | 높음 |
| 배터리 관리 | 경쟁 |
| 평균 생존 시간 | 2 — 5분 |

대부분의 플레이어가 협력하지 않기 때문에 풀 로비는 혼란스럽습니다. 귀하의 스쿼드는 Clark의 관심, 손전등 사용, 경로 옵션을 놓고 다른 47명의 플레이어와 경쟁하고 있습니다.

## Tier C: 풀 로비 솔로

풀 로비에서의 솔로 플레이는 솔로 플레이의 최악의 측면(협력 없음)과 풀 로비의 최악의 측면(최대 혼란)을 결합합니다. 신규 플레이어는 종종 이 구성으로 기본 설정됩니다.

**Tier C 솔로 풀 로비 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 50명 활성, 솔로 플레이어 |
| 협력 품질 | 없음 |
| Clark 조우율 | 매우 높음 |
| 배터리 관리 | 개인, 경쟁 |
| 평균 생존 시간 | 1 — 4분 |

Clark Huss rooms에서의 대부분의 죽음은 신규 플레이어가 역학을 이해하지 못하기 때문에 이 구성에서 발생합니다. 그들은 풀 로비에 솔로로 합류하고, Clark가 접근하면 공황 상태에 빠져 죽음으로 전력 질주합니다.

## Tier D: 낯선 사람들과 공개 로비

"자발적 스쿼드"를 위해 낯선 사람들과 함께 공개 로비에 합류하는 것은 모든 부정적인 요소를 결합하기 때문에 가장 낮은 순위의 구성입니다: 높은 플레이어 수, 낮은 협력, 일관성 없는 플레이어 행동.

**Tier D 공개 로비 구성:**

| 항목 | 값 |
|--------|-------|
| 플레이어 수 | 변동 (종종 가득 참) |
| 협력 품질 | 매우 나쁨 |
| Clark 조우율 | 매우 높음 |
| 배터리 관리 | 혼란 |
| 평균 생존 시간 | 30초 — 3분 |

공개 로비 구성은 학습 환경이지 생존 전략이 아닙니다. 신규 플레이어는 각 공개 로비 런을 연습으로 취급해야 하며, 진지한 생존 시도로 취급해서는 안 됩니다.

## 플레이어 실력 분포 효과

서버 내 실력 분포는 Clark의 표적 행동이 카운트가 아닌 플레이어 행동의 분산에 영향을 받기 때문에 난이도에 영향을 미칩니다.

**실력 분포 영향:**

| 실력 분포 | 난이도 영향 |
|--------------------|-------------------|
| 모두 숙련 | 낮은 난이도 (협력적, 예측 가능) |
| 혼합 숙련 | 중간 난이도 (예측할 수 없는 행동) |
| 대부분 신규 | 높은 난이도 (공황 행동 흔함) |
| 모두 신규 | 최고 난이도 (혼란) |

실력 분포는 직접 제어할 수는 없지만 서버 신선도와 상관관계가 있습니다. 새로운 서버는 신규 플레이어가 있는 경향이 있고, 확립된 서버는 베테랑이 있는 경향이 있습니다.

## 최적 서버 선택 전략

일관된 생존을 위해서는 올바른 서버 선택이 중요합니다. 아래 전략은 자신의 목표에 맞는 서버를 선택하는 데 도움이 됩니다.

**선택 의사 결정 트리:**

| 목표 | 권장 구성 |
|------|---------------------------|
| 오디오 기술 연습 | 부분 서버 솔로 |
| 친구와 함께 플레이 | 조직적 트리오 또는 콰트로 |
| 리더보드 등극 | 빈 서버의 조직적 트리오 |
| 기본 학습 | 풀 로비 솔로 (혼란 예상) |
| 스피드런 | 빈 서버 솔로 |

## 서버 새로 고침 타이밍

서버 새로 고침 타이밍은 플레이어 수와 실력 분포에 영향을 미칩니다. 언제 합류할지 알면 최적의 서버 조건을 찾는 데 도움이 됩니다.

**새로 고침 타이밍 패턴:**

| 시간대 | 서버 상태 |
|-------------|--------------|
| 이른 아침 | 대부분 비어 있음, 베테랑 플레이어 |
| 오후 | 혼합, 부분 서버 |
| 저녁 | 풀 로비, 혼합 실력 |
| 늦은 밤 | 부분 서버, 베테랑 |
| 주말 | 풀 로비, 혼합 실력 |

조직적 플레이의 최적 시간은 서버가 부분적이고 플레이어가 더 경험이 많은 경향이 있는 이른 아침이나 늦은 밤입니다.

## 서버 브라우저 도구

커뮤니티 서버 브라우저 도구는 최적의 서버 구성을 찾는 데 도움이 됩니다. 이 도구는 실시간 플레이어 수와 배터리 상태를 표시합니다.

**도구 기능:**

- 실시간 플레이어 수
- 서버 연령 (운영 기간)
- 평균 플레이어 레벨 표시기
- 신규 합류자를 위한 배터리 상태
- 최근 새로 고침된 서버

베테랑은 최적의 서버 조건을 중심으로 세션을 계획하기 위해 이러한 도구를 사용합니다.

## 자주 묻는 질문

**신규 플레이어에게 가장 좋은 서버 구성은 무엇인가요?**

10 — 30명의 부분 서버에서 솔로 플레이입니다. 이 구성은 압도적인 혼란 없이 연습을 제공합니다.

**항상 조직적 스쿼드와 플레이해야 하나요?**

진지한 생존 시도의 경우 그렇습니다. 무작위 공개 로비는 연습 환경일 뿐입니다.

**가득 찬 50인 서버는 항상 나쁜가요?**

반드시 그런 것은 아닙니다. 일부 풀 로비에는 좋은 성과를 내는 조직적 스쿼드가 있습니다. 도전은 헌신하기 전에 스쿼드가 조직적인지 식별하는 것입니다.

**조직적 스쿼드원을 어떻게 찾나요?**

커뮤니티 Discord와 Wiki 스쿼드 모집 섹션이 최상의 소스입니다. 많은 베테랑이 이러한 채널을 통해 스쿼드를 구성합니다.

**권장되는 최대 스쿼드 규모는 어떻게 되나요?**

콰트로(4명)가 조직적 플레이에 권장되는 최대 규모입니다. 더 큰 스쿼드는 이점을 초과하는 협력 부담을 도입합니다.

조직적 스쿼드를 효과적으로 만드는 협력 프로토콜에 대한 자세한 내용은 [협동 생존 가이드](/en/multiplayer/co-op-survival-guide/)를 참조하십시오. 솔로 플레이에 가장 효과적인 전략을 배우려면 [초보자 가이드](/en/guides/beginner-guide/)를 읽으십시오.


**티어 순위를 얼마나 자주 재평가해야 하나요?**

티어 순위는 주요 패치 후와 안정적인 기간에는 분기마다 재평가해야 합니다. 전략 효과는 게임 변경에 따라 변동됩니다. 베테랑은 시간이 지나면서 티어 순위를 추적하고 그에 따라 플레이 스타일을 조정합니다. 개인 티어 순위는 커뮤니티 합의와 다를 수 있습니다.

**티어 순위는 보편적인가요, 아니면 플랫폼별인가요?**

티어 순위에는 플랫폼별 변형이 있습니다. PC 플레이어는 오디오 의존 전략에서 이점을 갖습니다. 모바일 플레이어는 컨트롤 및 오디오 품질 차이로 인해 다른 접근 방식을 선호할 수 있습니다. 티어 순위를 자신의 플레이에 적용할 때 플랫폼을 고려하십시오.

**나만의 티어 순위를 어떻게 만들나요?**
