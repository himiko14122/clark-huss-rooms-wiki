## 코드 입력 모범 사례

코드를 입력할 때 입력 모범 사례를 따르면 오타와 대소문자 문제를 방지할 수 있습니다. 아래 사례들은 Roblox 코드 등록 전반에 적용됩니다.

### **코드 입력 사례:**

| 사례 | 이유 |
|----------|--------|
| 출처에서 복사-붙여넣기 | 오타 방지 |
| 대소문자 확인 | 코드는 대소문자를 구분함 |

| 문자 수 확인 | 잘못된 길이는 잘못된 코드를 의미함 |
| 한 번에 하나의 코드만 시도 | 어떤 코드가 실패했는지 쉽게 식별 가능 |

가장 흔한 등록 실패는 대소문자 표기 오류입니다. 항상 출처의 정확한 대소문자를 확인해 주세요.

## 일반적인 문제 해결

코드 시스템이 출시된 이후에도 다양한 이유로 등록이 실패할 수 있습니다. 아래 문제 해결 가이드는 흔한 이슈들을 다룹니다.

### **일반적인 등록 문제:**

| 문제 | 원인 | 해결책 |
|-------|-------|----------|
| "Code not found" | 오타 또는 만료된 코드 | 공식 출처에서 재확인 |
| "Already redeemed" | 해당 계정에서 이미 사용된 코드 | 인벤토리에서 보상 확인 |
| "Invalid code format" | 잘못된 문자 수 | 코드 길이 확인 |
| "Code system unavailable" | 서버 문제 | 대기 후 재시도 |
| "Region locked" | 특정 지역으로 제한된 코드 | 코드 제한 조건 확인 |
| "Server error" | Roblox 플랫폼 문제 | 나중에 다시 시도 |

대부분의 등록 실패는 오타 또는 만료된 코드 때문에 발생합니다. 문제 해결에 앞서 항상 공식 출처에서 코드를 확인해 주세요.

## 만료 코드 처리

코드가 만료되면 더 이상 등록이 불가능합니다. 아래 만료 코드 처리 절차는 발생 상황과 대응 방법을 설명합니다.

**만료 코드 절차:**

1. 만료된 코드 등록을 시도함
2. "code expired" 또는 유사한 오류 메시지를 받음
3. 공식 출처에서 코드 연장 여부를 확인함
4. 다른 활성 코드로 이동함

만료된 코드는 연장되지 않으며, 개발자는 일반적으로 만료된 코드를 재발급하지 않습니다. 코드를 놓치면 해당 보상을 받을 기회를 잃는다는 뜻입니다.

## 모바일 vs PC 등록

등록은 모바일과 PC 모두에서 가능하지만, 경험에는 차이가 있습니다. 아래 비교는 최적의 플랫폼을 선택하는 데 도움이 됩니다.

**플랫폼 비교:**

| 항목 | PC | 모바일 |
|--------|----|----|
| 코드 입력 속도 | 더 빠름 (물리 키보드) | 더 느림 (터치 키보드) |
| 복사-붙여넣기 지원 | 완전 지원 | 제한적 |
| UI 반응성 | 높음 | 가변적 |
| 알림 전달 | 이메일, 브라우저 | 푸시 알림 |

PC 플레이어는 물리 키보드를 통한 더 빠른 타이핑과 안정적인 복사-붙여넣기로 인해 코드 입력 속도에서 유리합니다. 모바일 플레이어는 가능하면 복사-붙여넣기 기능을 활용하시기 바랍니다.

**코드 출처 신뢰도:**

| 출처 | 신뢰도 |
|--------|-------------|

| 커뮤니티 Wiki | 높음 (베테랑들이 관리) |

등록 전에 최소 두 곳 이상의 출처에서 코드를 확인하시기 바랍니다. 검증되지 않은 코드는 만료되었거나 가짜이거나 오타를 포함할 수 있습니다.

**코드 현황 참고:**

- 활성 코드: 현재 0개, 시스템 미구현
- 만료 코드: 0개, 출시된 코드 없음
- 코드 시스템 상태: 개발자에 의해 아직 구현되지 않음
- 예상 출시 시기: 업계 패턴 기준 2026년 말 ~ 2027년 초
- 검증 출처: Roblox 게임 페이지, 개발자 소셜 미디어, 커뮤니티 Wiki
- 보상 종류: 재화, 코스메틱, 부스트, 칭호, 배지
- 배포 패턴: 업데이트 출시, 마일스톤, 기념일, 이벤트

**검증 체크리스트:**

- 등록 전에 최소 두 곳 이상의 공식 출처에서 코드 확인
- 시간 낭비를 피하기 위해 코드 만료일 확인
- 문자 수가 코드 형식의 예상 길이와 일치하는지 확인
- 대소문자가 출처와 정확히 일치하는지 확인
- 제출 전 앞뒤 공백 모두 제거
- 계정이 모든 등록 요구 사항을 충족하는지 확인
- 서버 응답이 더 원활한 비피크 시간대에 등록 시도
- 지속적 문제는 적절한 커뮤니티 채널을 통해 신고


## 자주 묻는 질문 (FAQ)

**모바일에서 코드를 등록할 수 있나요?**

네, 가능하지만 터치 키보드의 한계로 인해 PC보다 속도가 느립니다. 가능한 경우 복사-붙여넣기 기능을 활용하시기 바랍니다.

**코드를 잘못 입력하면 어떻게 되나요?**

코드가 유효하지 않다는 오류 메시지가 표시됩니다. 각 문자를 주의 깊게 다시 입력해 주세요.

**같은 코드를 두 번 등록할 수 있나요?**

아닙니다. 각 코드는 계정당 한 번만 등록할 수 있습니다. 두 번 등록을 시도하면 "already redeemed" 오류가 반환됩니다.

**코드는 모든 지역에서 작동하나요?**

대부분의 코드는 전역적으로 작동하지만, 일부 코드는 지역 제한이 있습니다. 코드 설명에서 지역 제한 여부를 확인해 주세요.

**코드는 보통 얼마나 오래 유효한가요?**

Roblox 호러 게임 코드는 일반적으로 2~4주간 유효하지만, 몇 달간 유효한 경우도 있습니다. 한정 기간 이벤트 코드는 며칠만 유효할 수도 있습니다.

현재 코드 현황에 대한 자세한 내용은 [2026년 7월 활성 코드](/en/codes/active-codes-july-2026/) 페이지를 참고하세요. 코드가 작동하지 않을 때 해야 할 일은 [코드 작동 불능](/en/codes/codes-not-working/) 문서를 확인해 주세요.


**코드는 언제부터 사용 가능해질 예정인가요?**

코드는 일반적으로 핵심 게임플레이가 안정화된 Early Access 후반부에 등장합니다. 유사한 Roblox 호러 게임들을 기준으로, 2026년 말에서 2027년 초 사이에 코드가 출시될 수 있습니다. 개발자가 구체적인 일정을 발표하지 않았으므로, 모든 날짜는 업계 패턴에 기반한 추정치입니다.

**코드가 합법적인지 어떻게 알 수 있나요?**

등록 전에 여러 공식 출처에서 코드를 확인하시기 바랍니다. Roblox 게임 페이지, 개발자 소셜 미디어, 신뢰할 수 있는 커뮤니티 채널이 신뢰할 만한 출처입니다. 무작위 웹사이트와 검증되지 않은 소셜 미디어 게시물에는 만료되었거나 가짜이거나 오타가 포함된 코드가 있을 수 있습니다. 가능한 경우 항상 코드를 교차 검증해 주세요.

**올바르게 입력했는데도 등록이 실패하면 어떻게 해야 하나요?**
