## 脅威ティアフレームワーク

Clarkの脅威は、不活性から切迫まで及ぶ6段階スケールで評価されます。各ティアには特定の音声キュー、検知範囲、対策要件があります。

### **脅威ティアの定義：**

| ティア | ラベル | Clarkの状態 | 検知範囲 | 対策戦略 |
|------|-------|-------------|-----------------|------------------|
| S | 切迫 | アクティブチェイス、視線内 | 20メートル以上 | 全速力スプリント、懐中電灯オフ、角ブレイク |
| A | 高 | 囁き、音跡追跡中 | 12〜18メートル | 制御された撤退、音響モニタリング |
| B | 中 | 呼吸リズム、1つの通路 | 6〜12メートル | 一時停止、方向確認、逃走計画 |
| C | 低 | 足音ドスン、隣接部屋 | 3〜6メートル | ゆっくり移動、注意深く聴く |
| D | 遠方 | ハートビートのみ、2つの通路 | 1〜3メートル | 通常ペース、懐中電灯クリック許可 |
| F | 不活性 | 範囲外またはクールダウン | 0メートル | 懐中電灯自由使用、頻繁クリック可 |

ティアフレームワークにより、任意の音声キューを聞いてから1秒以内にClarkの脅威を分類できます。ベテランは意識的努力なしに自動的に分類します。

## ティアS：切迫脅威

ティアSは最高の脅威レベルであり、Clarkが視線の可能性のある状態でアクティブチェイス中である場合に発生します。生存には即座の決断的な行動が必要です。

### **ティアSのトリガー：**

- スプリントバースト音の手がかり
- 囁き断片と足音ドスンの組み合わせ
- Clark接近の視覚確認
- 部隊メイトのコールアウト「チェイス、今すぐ全力スプリント」

### **ティアS対応プロトコル：**

| ステップ | 行動 | 必要時間 |
|------|--------|---------------|
| 1 | 選択した方向に全力スプリント | 0〜1秒 |
| 2 | 懐中電灯オフ | 0.5秒 |
| 3 | 最寄りの交差点で角ブレイク | 1〜3秒 |
| 4 | 2回目の角ブレイク | 3〜6秒 |
| 5 | Clarkの離脱を確認 | 6〜10秒 |

ティアSプロトコルの実行には10秒かかり、完全なスタミナ蓄えが必要です。スタミナが低い状態でティアSに入ると、生存確率は60%低下します。

## ティアA：高脅威

ティアAは2番目に高い脅威であり、Clarkがあなたの音跡を積極的に追跡しているが、まだチェイスに関与していない場合に発生します。このティアでは、音跡を断ち切るための10〜15秒のウィンドウがあります。

### **ティアAのトリガー：**

- 繰り返される囁き断片
- 速い呼吸リズム
- 100BPM以上に加速するハートビート
- Clarkの発声（単一単語の呟き）

**ティアA対策戦略：**

1. スプリントを直ちに停止 — 彼が追跡しているのはスプリント音です
2. 歩行ペースのみに切り替え
3. 鋭角に曲がって音跡を断つ
4. 懐中電灯を1回クリックしてClarkの位置を確認
5. 15秒待ってClarkが離脱するのを待つ

ティアAの対策戦略は忍耐です。新規プレイヤーはパニックになってスプリントし、それがティアSへの上昇を確実にします。ベテランは待ち、Clarkに音跡を自然に失わせます。

## ティアB：中脅威

ティアBはミッドゲームで最も一般的な脅威レベルであり、Clarkが音声検知範囲内にいるが、あなたの具体的な位置を特定していない場合に発生します。このティアは生存判断のスイートスポットです。

**ティアBのトリガー：**

- 通常の呼吸リズム（2秒に1回呼吸）
- ゆっくりしたテンポの足音ドスン
- 通常範囲のハートビート（60〜80BPM）
- 遠方の囁き断片

**ティアB判断フレームワーク：**

| Clarkの位置 | 推奨行動 |
|----------------|--------------------|
| 部隊の後ろ | 前進継続、ややペース上昇 |
| 部隊の前 | 一時停止、逃走ルートの確認 |
| 左側 | 右通路へ移動 |
| 右側 | 左通路へ移動 |
| 同じ通路 | 制御された撤退 |

ティアBは、脅威を過小評価するため、ほとんどのプレイヤーが死亡するティアです。呼吸リズムは管理可能そうに聞こえますが、Clarkは積極的に聴取しており、数秒以内にティアAに上昇させることができます。

## ティアC：低脅威

ティアCはルーチン航行ティアであり、Clarkは近くにいるが積極的に脅威を与えていません。走行時間のほとんどはティアCで費やされるため、最適化が最も重要です。

**ティアCの特徴：**

- ゆっくりした足音ドスン（秒間2回）
- ゆっくりした呼吸リズム（4秒に1回呼吸）
- 遠方のハートビート（50〜60BPM）
- 囁き断片なし

**ティアC懐中電灯ポリシー：**

| バッテリー状態 | 懐中電灯の動作 |
|---------------|---------------------|
| 100〜70% | 通常クリックパターン |
| 70〜50% | 単一クリックに減らす |
| 50〜25% | 判断ポイントでのみクリック |
| 25%未満 | 音響のみ航行 |

ティアCはまた、ほとんどの空間マッピングが行われる場所でもあります。ティアAとSはマッピングの時間を許さないため、ティアCでメンタルマップを構築してください。

## ティアD：遠方脅威

ティアDは最も安全な非不活性ティアであり、Clarkがサーバーの遠方エリアを巡回していることを表します。序盤のほとんどの時間はティアDで費やされます。

**ティアDの特徴：**

- 聞こえるが音量の低いハートビート
- 呼吸または足音の手がかりなし
- 囁き断片なし
- 安定したパルスリズム

**ティアDの機会ウィンドウ：**

ティアDは懐中電灯探索と空間マッピングに最適なウィンドウを提供します。ティアDの懐中電灯ポリシーは、Clarkの検知範囲が最小限であるため、より多くのクリックを許可します。

| 活動 | ティアD推奨事項 |
|----------|----------------------|
| 懐中電灯クリック | 高頻度、毎分最大10クリック |
| 空間マッピング | 通路の完全探索 |
| 部隊再編成 | 一時停止と計画 |
| アイテム収集 | 徹底的な探索 |
| スタミナ回復 | 完全休息 |

ベテランプレイヤーはティアDウィンドウを使用して次のティア上昇に備えます。この準備が、ティアBを生存することとティアAで死亡することの違いを生みます。

## ティアF：不活性状態

ティアFは、Clarkが音声範囲外、クールダウンウィンドウ内、または検知を防ぐサーバー状態にある場合の不活性状態を表します。ティアFは、攻撃的な懐中電灯使用と攻撃的な航行のための最も安全な時間です。

**ティアFのトリガー：**

- Clarkのハートビートが30秒以上聞こえない
- 部隊がマークされた安全通路に到達
- 離脱後のアクティブクールダウン中のClark
- サーバー状態が検知を防止（非常に稀）

**ティアF懐中電灯ポリシー：**

ティアFでは、懐中電灯の使用は無制限です。航行に必要なだけ頻繁にクリックしてください。これは、通路レイアウト、アイテム位置、出口インジケーターに関する情報を収集するウィンドウです。

## ティア遷移

Clarkのティアは走行中に絶えず変化し、遷移は予測可能なパターンに従います。遷移を認識することで、次のエスカレーションに備えることができます。

**一般的なティア遷移：**

| 移行元 | 移行先 | トリガー | 準備時間 |
|------|-----|---------|------------------|
| D | C | ハートビートが大きくなる | 30秒 |
| C | B | 呼吸が聞こえ始める | 15秒 |
| B | A | 囁き断片が始まる | 10秒 |

準備時間は、次のティア変化までの時間を伝えます。その時間を使用して適切な対応を準備してください。

## 脅威ティア修飾子

特定の条件がClarkの脅威ティアを修飾し、標準ティアフレームワークをよりニュアンス豊かにします。修飾子を理解することで、過小評価を防ぎます。

**脅威修飾子：**

| 修飾子 | ティア調整 |
|----------|-----------------|
| サーバーロック作動中 | 全ティアが1つ上昇 |
| 部隊分離 | 個別脅威がティアAに増加 |
| 懐中電灯持続使用 | 脅威ティアが1つ増加 |
| 同じ通路でのスプリント | 脅威ティアが2つ増加 |
| 開放部屋への進入 | 脅威ティアが1つ増加 |
| 開放部屋からの退出 | 脅威ティアが1つ減少 |
| バッテリー25%未満 | 懐中電灯ベース対策戦略を使用不可 |
| スタミナ30%未満 | スプリントベース対策戦略を使用不可 |

修飾子は基本ティアの上に適用されます。ClarkがティアBで、あなたが同じ通路でスプリントしている場合、有効脅威はティアSです。

## よくある質問

**Clark Huss roomsで最も一般的な死因は何ですか？**

プレイヤーがティアBキューに正しく対応しなかったことによるティアBからティアSへのエスカレーションです。エスカレーションはわずか5秒で発生し、応答ウィンドウは短いです。

**ティアフレームワークは将来のエンティティにも適用できますか？**

はい、ティアフレームワークは拡張可能に設計されています。新しいエンティティが追加される際、検知範囲と行動パターンに基づいて同じティアシステムに適合します。

**最も良いティアはどれですか？**

ティアDが最も安全な非不活性ティアです。ティアFは技術的により安全ですが稀です。走行時間のほとんどはティアCとBで費やされます。

**ティアエスカレーションはどのくらいの速さで発生しますか？**

複数のミスを犯した場合（同じ通路でのスプリント、持続懐中電灯、音響足跡）、ティアDからティアSへのエスカレーションは30秒以内に発生する可能性があります。エスカレーションは速く、容赦ありません。

**ティア変化に常にすぐに対応すべきですか？**

はい。エスカレーションウィンドウが短いため、ティア変化には即座の対応が必要です。遅延はさらなるエスカレーションを引き起こします。

ティア変化を引き起こすClarkの特定の音声キューの詳細については、[音声キュー詳細ガイド](/en/guides/audio-cues-detailed/)を参照してください。ティアS状況での脱出戦術を学ぶには、[Clarkからの脱出](/en/guides/escaping-clark/)をお読みください。


**ティアランキングをどのくらいの頻度で再評価すべきですか？**

ティアランキングは、メジャーパッチ後と安定期間中は四半期ごとに再評価する必要があります。戦略効果はゲームの変化とともに変化します。ベテランはティアランキングを経時的に追跡し、それに応じてプレイスタイルを調整します。個人的なティアランキングはコミュニティのコンセンサスとは異なる場合があります。

**ティアランキングは普遍的ですか、それともプラットフォーム固有ですか？**

ティアランキングにはプラットフォーム固有のバリエーションがあります。PCプレイヤーは音響依存戦略で利点があります。モバイルプレイヤーは、操作性と音質の差により、異なるアプローチを好む場合があります。ティアランキングをプレイに適用する際はプラットフォームを考慮してください。

**自分のティアランキングを作成するにはどうすればよいですか？**

複数のランにわたる異なる戦略での自分のパフォーマンスを追跡します。成功率、生存時間、楽しさをメモします。個人的なデータをコミュニティのコンセンサスと組み合わせて、独自のランキングを形成します。経験を重ね、ゲームが進化するにつれてランキングを更新してください。

**ティアランキングは私の戦略選択に影響を与えるべきですか？**

ティアランキングは戦略選択に情報を提供しますが、決定づけるべきではありません。個人的好みとプレイスタイルが効果と同様に重要です。強みに合わないより強い戦略よりも、あなたの強みに合致するわずかに弱い戦略の方が優れたパフォーマンスを発揮する場合があります。ランキングを個人的な要素とバランスさせてください。

**ティアランキングとメタの違いは何ですか？**

ティアランキングは個々の戦略を孤立して評価します。メタは支配的な組み合わせ、対策戦略、バランス変化を含む全体的な戦略環境を記述します。両方はゲーム状態を理解するために有用です。メタ分析はコンポーネントとしてティアランキングを参照することがよくあります。

**部隊戦略はティアランキングにどのように影響しますか？**

部隊戦略は、調整が効果を乗算するため、solo戦略よりも高くランク付けされることがよくあります。solo戦略はsoloプレイコンテキストでより高くランク付けされます。ティアランキングを評価する際、戦略がsolo用か部隊用かを考慮してください。一部の戦略は一方のコンテキストでのみ機能します。

**ティアランキングは間違っている可能性がありますか？**

ティアランキングは観察に基づくコミュニティのコンセンサスであり、絶対的な真理ではありません。個人の経験はコンセンサスとは異なる場合があります。より低くランク付けされた一部の戦略は、特定のプレイヤーにより効果的である場合があります。ティアランキングを絶対的なルールではなく、ガイダンスとして使用してください。
