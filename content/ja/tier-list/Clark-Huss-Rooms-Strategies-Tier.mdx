Clark Huss roomsには複数の有効なサバイバル戦略が存在し、最強の戦略はプラットフォーム、スコードサイズ、個人のプレイスタイルによって異なります。新規プレイヤーはパニックスプリントをデフォルトにしがちですが、それは生産的に感じるためです。しかし、データは一貫して、コントロールされた戦略がパニック戦略を大きく上回ることを示しています。このtierリストは、主要なサバイバル戦略をS（最も効果的）からC（最も信頼性が低い）までランク付けし、それぞれのアプローチのトレードオフを説明し、特定の状況で使用すべき戦略を推奨します。

このtierリストは2026年7月時点のアーリーアクセスメタを反映しており、Clarkの挙動とバランスを調整するパッチと共に進化します。

## 戦略Tierフレームワーク

各戦略は、生存効果、学習曲線、一貫性の3つの要素に基づいて4段階のスケールで評価されます。要素は異なるプレイヤータイプに対する総合的な実行可能性を決定します。

### **戦略tierの要素：**

| 要素 | 重み | 説明 |
|--------|--------|-------------|
| 生存効果 | 50% | 戦略が成功するランにつながる頻度 |
| 学習曲線 | 30% | 新規プレイヤーが戦略を採用する速度 |
| 一貫性 | 20% | 異なる状況で戦略がどの程度安定して機能するか |

総合的な重み付けが最終的なtierランキングを決定します。広範な練習を要するが効果の高い戦略は、学習曲線にもかかわらず高くランクされることがあります。

## Tier S：コントロールドリトリート戦略

コントロールドリトリートは、効果、学習曲線、一貫性のバランスが取れているため、最高ランクの戦略です。ベテランは、この戦略で他のどの戦略よりも長いランを一貫して達成しています。

### **コントロールドリトリートの特性：**

| 項目 | 説明 |
|--------|-------------|
| 移動ペース | 歩行のみ、逃走時のみ時折スプリント |
| フラッシュライト使用 | クリックのみモード、バッテリー節約 |
| 音声フォーカ | 継続的なモニタリング、意思決定駆動 |
| リスクプロファイル | 低リスク、遅い進行 |
| 最適なスコードサイズ | 全て対応（ソロからフルロビーまで） |

### **コントロールドリトリート実行シーケンス：**

1. 通路を一定のペースで歩行する
2. 各分岐点での意思決定時にフラッシュライトを1回クリックする
3. Clarkの音声テルを常に聞き取る
4. 心拍が変化したら少し立ち止まる
5. Clarkの行動ティアに基づいてペースを調整する
6. Tier Sの脅威がアクティブな時のみスプリントする

この戦略の有効性は、Clarkの検知機会を減らしながら進行を維持することにあります。

## Tier A：オーディオファーストムーブメント戦略

オーディオファーストムーブメントは2番目にランクされた戦略で、コントロールドリトリートと多くの特性を共有しています。違いは、主要な情報源として音声を明示的に重視する点です。

### **オーディオファーストの特性：**

| 項目 | 説明 |
|--------|-------------|
| 移動ペース | 変動可能、音声状態に合わせる |
| フラッシュライト使用 | 最小限、音声優先 |
| 音声フォーカ | 継続的、先回りのリスニング |
| リスクプロファイル | 中リスク、音声の習熟が必要 |
| 最適なスコードサイズ | デュオからクアトロ |

**オーディオファーストの実行：**

1. 各分岐点で立ち止まり、進行前に2〜3秒間耳を傾ける
2. 音声キューを使用してClarkが近くにいるかを判断する
3. 未探索エリアに入る時のみフラッシュライトをクリックする
4. 音声情報に基づいてルートを調整する
5. 音声の発見をスコードに共有する（マルチプレイヤー）

この戦略には強力な音声解釈スキルが必要です。音声トレーニングシーケンスを完了したプレイヤーにとって非常に効果的です。

## Tier B：サイレントラン戦略

サイレントランは3番目にランクされた戦略で、常時最小限のサウンドプロファイルに焦点を当てています。戦略は効果的ですが遅いので、特定の状況での使用に限定されます。

**サイレントランの特性：**

| 項目 | 説明 |
|--------|-------------|
| 移動ペース | ゆっくり歩行、スプリントなし |
| フラッシュライト使用 | 可能な限り完全にオフ |
| 音声フォーカ | 受動的リスニング、積極的なスキャンなし |
| リスクプロファイル | 低リスク、非常に遅い進行 |
| 最適なスコードサイズ | ソロのみ |

**サイレントランの実行：**

1. 進行を維持できる最も遅いペースで移動する
2. フラッシュライトは絶対に必要な場合以外はオフ
3. 受動的に聞く、積極的にスキャンしない
4. Clarkが離れるのを待ってから続行する
5. 環境音を利用してナビゲートする

サイレントランは、時間を投資できるソロプレイヤーにとって最も効果的です。マルチプレイヤーでは、遅いペースがスクードメイトを苛立たせ、スピードアップさせる圧力を生み出します。

## Tier B：スクードコーディネーション戦略

スクードコーディネーションは、効果がスクードの質に大きく依存するため、サイレントランと並んでTier Bにランクされています。よく連携されたスクードは、連携されていないものよりも大幅に優れていますが、連携を達成するには投資が必要です。

**スクードコーディネーションの特性：**

| 項目 | 説明 |
|--------|-------------|
| 移動ペース | 変動可能、リードが制御 |
| フラッシュライト使用 | 連携済み、ライトマネージャーが制御 |
| 音声フォーカ | 役割間で分散 |
| リスクプロファイル | 連携されていれば低リスク、そうでなければ高 |
| 最適なスコードサイズ | トリオからクアトロ（スイートスポット） |

**スクードコーディネーションの実行：**

1. サーバーロック前にリード、リアガード、ライトマネージャーを任命する
2. 標準化されたコールアウト用語を使用する
3. フォーメーションで移動する（ウェッジまたは一列縦隊）
4. ライトマネージャーがすべてのフラッシュライトクリックを制御する
5. リアガードがClarkの音声を監視し、脅威をコールアウトする

この戦略にはゲーム前の合意とリハーサルが必要です。ランダムなパブリックロビーでは効果的に実行できません。

## Tier C：パニックスプリント戦略

パニックスプリントは、生産的に感じられますが、一貫して失敗するため、最低ランクの戦略です。新規プレイヤーがデフォルトで使用するため、なぜ機能しないのかを理解してもらうためにtierリストに含まれています。

**パニックスプリントの特性：**

| 項目 | 説明 |
|--------|-------------|
| 移動ペース | 継続的なスプリント |
| フラッシュライト使用 | スパムクリック、多くの場合持続的 |
| 音声フォーカ | なし、自分の音で圧倒される |
| リスクプロファイル | 非常に高い、Clarkの検知を保証 |
| 最適なスコードサイズ | なし |

**パニックスプリントが失敗する理由：**

| 理由 | 影響 |
|--------|--------|
| スプリントの音は大きい | Clarkがプレイヤーを直接追跡する |
| スプリントはスタミナを消耗する | 後の逃走用の予備がない |
| フラッシュライトのスパムは位置を露出する | 壁越し、二重露出 |
| 音声モニタリングなし | Clarkの接近を聞くことができない |
| 予測可能な方向 | Clarkが簡単に迎撃できる |

パニックスプリントは、新規プレイヤーがClarkを聞いた時に本能的に使用する戦略です。ベテランはパニックスパイラルを認識し、始まる前にコントロールドリトリートでそれを中断します。

## プラットフォーム別の戦略効果

戦略効果は、PCとモバイルでは異なるコントロール、音声品質、画面の可視性のため、プラットフォームによって異なります。

**プラットフォーム別の戦略効果：**

| 戦略 | PC | モバイル |
|----------|----|----|
| コントロールドリトリート | 高 | 高 |
| オーディオファーストムーブメント | 高 | 中（音声品質が変動） |
| サイレントラン | 高 | 中（タッチコントロールの精度が低い） |
| スクードコーディネーション | 高 | 低（プッシュトゥトークが難しい） |
| パニックスプリント | 低 | 低 |

PCプレイヤーは音声品質と精密なコントロールで優位性があり、音声依存の戦略をより効果的にします。モバイルプレイヤーは、正確なタイミングを必要としない戦略の恩恵を受けます。

## スコードサイズ別の戦略効果

戦略効果は、連携のオーバーヘッドと役割の分散がプレイヤー数で変化するため、スコードサイズによって異なります。

**スコードサイズ別の戦略効果：**

| 戦略 | ソロ | デュオ | トリオ | クアトロ | フルロビー |
|----------|------|------|------|---------|------------|
| コントロールドリトリート | 高 | 高 | 高 | 高 | 中 |
| オーディオファーストムーブメント | 高 | 高 | 高 | 中 | 低 |
| サイレントラン | 高 | 中 | 低 | 低 | 低 |
| スクードコーディネーション | 該当なし | 中 | 高 | 高 | 中 |
| パニックスプリント | 低 | 低 | 低 | 低 | 低 |

コントロールドリトリートは普遍的に効果的なため、最高位にランクされています。他の戦略はより状況的です。

## 戦略のトレードオフ

各戦略には、その有用性に影響を与えるトレードオフがあります。トレードオフを理解することは、状況に合った適切な戦略を選択するのに役立ちます。

**戦略のトレードオフ：**

| 戦略 | 長所 | 短所 |
|----------|------|------|
| コントロールドリトリート | 信頼性、一貫性、低いスキル床 | 進行が遅い |
| オーディオファーストムーブメント | 訓練された耳で効果的 | 音声の習熟が必要 |
| サイレントラン | 最大のステルス | 非常に遅い、スクードでは非実用的 |
| スクードコーディネーション | 実行された場合の強力なパフォーマンス | ゲーム前の合意が必要 |
| パニックスプリント | 速い感覚、本能的 | 失敗が保証される |

## メタ進化の追跡

戦略メタは、Clarkの挙動を調整するパッチと共に進化します。2026年7月の時点で、コントロールドリトリートとオーディオファーストムーブメントがメタを支配しています。今後のパッチでランキングが変わる可能性があります。

**最近のメタシフト：**

| パッチ | 戦略への影響 |
|-------|----------------------|
| 2026年7月 | Clarkの音声感度がやや低下、パニックスプリントの即死率が低下 |
| 2026年6月 | スクード連携ボーナスが追加、連携プレイがやや強力に |
| 2026年5月 | フラッシュライトバッテリーが増加、オーディオファーストムーブメントがより持続可能に |

メタシフトは小さいですが、時間の経過と共に蓄積されます。ベテランはパッチを追跡して戦略選択を調整します。

## よくある質問

**全く新しいプレイヤーにとって最強の戦略は何ですか？**

コントロールドリトリートは、最も低いスキル床と最も高い一貫性を持つため、最強の開始戦略です。新規プレイヤーは基本をマスターするまで、コントロールドリトリートをデフォルトにするべきです。

**どの戦略が最も高いスキルシーリングを持っていますか？**

スクードコーディネーションは、複数のプレイヤーが同期して実行する必要があるため、最も高いスキルシーリングを持っています。完全に連携されたスクードは、生存時間でどのソロ戦略よりも30〜50%優れています。

**ラン中に戦略を切り替えるべきですか？**

場合によっては。現在の戦略が失敗している（Clarkとの遭遇の繰り返し、バッテリー残量少ない、スタミナ少ない）場合、コントロールドリトリートへの切り替えは安全なフォールバックです。「絶望的な一手」としてパニックスプリントへの切り替えは避けてください。

**戦略はPCとモバイルで異なりますか？**

はい。オーディオファーストムーブメントは、音声品質の変動のため、モバイルではより困難です。モバイルプレイヤーは、コントロールドリトリートまたはサイレントランをデフォルトにするべきです。

**メタはパッチ後にどう進化しますか？**

各パッチ後、コミュニティのコンセンサスがシフトします。tierリストは、パッチ後の最初の週で観察されたラン結果に基づいて更新されます。

コントロールドリトリートの実行シーケンスの詳細については、[Clarkからの脱出ガイド](/en/guides/escaping-clark/)を参照してください。オーディオファーストムーブメントを詳しく学ぶには、[音声ナビゲーション](/en/guides/audio-navigation/)をお読みください。


**ティアランキングをどのくらいの頻度で再評価すべきですか？**

ティアランキングは、メジャーアップデートの後と安定した期間中は四半期ごとに再評価されるべきです。戦略の有効性はゲームの変更と共に変化します。ベテランはティアランキングを経時的に追跡し、プレイスタイルを調整します。個人のティアランキングは、コミュニティのコンセンサスとは異なる場合があります。

**ティアランキングは普遍的ですか、それともプラットフォーム固有ですか？**

ティアランキングには、プラットフォーム固有のバリエーションがあります。PCプレイヤーは、音声依存の戦略で優位性があります。モバイルプレイヤーは、コントロールと音声品質の違いにより、別のアプローチを好む場合があります。ティアランキングをプレイに適用する際は、プラットフォームを考慮してください。

**自分のティアランキングを作成するにはどうすればよいですか？**

異なる戦略で複数のランにわたる自分のパフォーマンスを追跡します。成功率、生存時間、楽しさをメモします。個人のデータとコミュニティのコンセンサスを組み合わせて、独自のランキングを形成します。経験とゲーム進化に伴い、ランキングを更新します。

**ティアランキングは戦略選択に影響を与えるべきですか？**

ティアランキングは戦略選択を通知するものであり、指示するものではありません。効果と同様に、個人の好みとプレイスタイルが重要です。自分の長所に合ったやや弱い戦略が、プレイスタイルに合わないより強い戦略を上回る場合があります。ランキングを個人的な要素とバランスしてください。

**ティアランキングとメタの違いは何ですか？**

ティアランキングは、個別戦略を孤立して評価します。メタは、支配的な組み合わせ、カウンタ戦略、バランスの変化を含む全体的な戦略的状況を説明します。両方ともゲームの状態を理解するのに役立ちます。メタ分析は、コンポーネントとしてティアランキングを参照することが多いです。

**スクード戦略はティアランキングにどのように影響しますか？**

スクード戦略は、連携が効果を乗算するため、しばしばソロ戦略よりも高くランクされます。ソロ戦略は、ソロプレイのコンテキストでより高くランクされます。ティアランキングを評価する際は、戦略がソロ用かスクード用かを考慮してください。一部の戦略は1つのコンテキストでのみ機能します。

**ティアランキングは間違っている可能性がありますか？**

ティアランキングは、観察に基づくコミュニティのコンセンサスであり、絶対的な真理ではありません。個々の経験はコンセンサスとは異なる場合があります。より低くランクされているいくつかの戦略は、特定のプレイヤーにとってはより良く機能する場合があります。ティアランキングを絶対的なルールではなく、ガイダンスとして使用してください。
