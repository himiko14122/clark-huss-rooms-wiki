Clark Huss rooms は約12種類の固定パター library から通路を生成し、各ルームタイプには独自のナビゲーション特性、安全性プロファイル、戦術的用途があります。どのルームタイプが安全で、どれが危険で、どれが戦術的に価値があるかを理解することは、空間マッピングと戦略的計画に不可欠です。新しいプレイヤーはすべての通路を同じように扱うため、準備不足で危険なルームに入ってしまいます。

この tier リストは、12種類のルームタイプを S(最も戦術的に価値がある) から F(最も役に立たない) までランク付けし、それぞれのナビゲーション特性を説明し、ランの各フェーズで優先すべきルームタイプについての推奨事項を提供します。オーディオと flashlight のクリックパターンでルームタイプを素早く識別する方法も学習できます。

## ルームタイプ tier フレームワーク

各ルームタイプは、ナビゲーション価値、Clark 遭遇時の安全性、戦術的ユーティリティの3つの要素に基づいて5段階のスケールでランク付けされています。tier は、どのルームに最初に入るか、どのルームを避けるべきかを優先順位付けするのに役立ちます。

### **ルームタイプ tier の要素:**

| 要素 | 重み | 説明 |
|--------|--------|-------------|
| ナビゲーション価値 | 40% | ルームが空間マッピングにどれだけ役立つか |
| Clark 遭遇時の安全性 | 40% | ルームが Clark の発見に対してどれだけ脆弱か |
| 戦術的ユーティリティ | 20% | 脱出または再集合のための戦略的価値 |

重み付けを組み合わせることで、S から F までの単一 tier ランキングが生成されます。以下の tier リストはこのフレームワークを使用して12種類のルームタイプをすべてランク付けしています。

## Tier S: 戦略的オープルーム

Tier S ルームは、空間マッピング、脱出ルート、 squad 再集合に戦術的価値を提供する大きなオープンスペースです。これらのルームはチェイス中に一時停止するのに最も安全な場所です。

### **Tier S ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| ハブルーム | 4つ以上のドアがある中央エリア | マップチェックポイント、squad 再集合 |
| 階段 | 構造が見える複数レベルアクセス | ナビゲーションランドマーク、脱出ルート |
| エコーチャンバー | 独特の残響を持つ大きなルーム | オーディランドマーク、オーディオキュー訓練 |

### **Tier S ルームの戦術的優位性:**

- 脱出のための複数の出口オプション
- ナビゲーション用のオーディランドマーク
- squad フォーメーション機動のためのスペース
- 空間記憶のための視覚的ランドマーク

これらのルームは、procedural generator がその出現頻度を制限するため、まれです。見つけたら、復帰地点として心に留めておいてください。

## Tier A: 長い通路のジャンクション

Tier A ルームは、複数の通路を接続するジャンクションポイントです。ルート選択を可能にし、チェイス中にコーナーブレイクオプションを提供するため、ナビゲーションに価値があります。

### **Tier A ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| クロスジャンクション | 4方向の交差点 | ルート選択、脱出オプション |
| T字ジャンクション | 3方向の交差点 | ルート選択 |
| L字ジャンクション | 2方向のコーナー | コーナーブレイク、脱出ルート |

**Tier A ルームの戦術的優位性:**

- 複数の方向オプション
- チェイス用のコーナーブレイク形状
- 予測可能なオーディオ挙動
- 頻繁な生成(マッピングに適している)

これらは最も一般的なルームタイプであり、メンタルマップの骨格を形成します。ベテランはこれらのルームに入ってから1秒以内に識別します。

## Tier B: 標準的なイエローホール

Tier B ルームは、procedurally generated レイアウトの大部分を占める標準的な通路です。ナビゲーションは安全ですが、基本的な接続以外の戦術的価値は限られています。

**Tier B ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| 長い直線ホール | 30メートル以上、単一方向 | スタミナ回復、flashlight 節約 |
| 標準イエロー通路 | 10〜30メートル、単一方向 | 標準ナビゲーション |
| 曲線通路 | 直線ではない経路、単一方向 | 視覚的な多様性、オーディオ landmark |

**Tier B ルームの戦術的考察:**

- 長い直線ホールは、Clark が後ろから chase すると death trap になる可能性がある
- 曲線通路はオーディオ line-of-sight を遮り、回避に便利
- 標準イエロー通路はナビゲーションの主力である

これらのルームが procedural レイアウトを埋めます。ほとんどの時間を Tier B ルームで過ごすため、ナビゲーション規律が重要です。

## Tier C: あいまいなスペース

Tier C ルームは、安全性とナビゲーション特性が特定の条件に依存するため、戦術的価値が不確定です。コミットする前に慎重な評価が必要です。

**Tier C ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| 広い通路ルーム | 単一方向、標準より広い | 不明、侵入時に評価 |
| ロックドア付きジャンクション | 1つのロックされた出口を持つ3方向 | 条件付きルート選択 |
| 部分的に開いたルーム | 構造的障害物がある | 防御位置 |

**Tier C ルーム評価トリガー:**

- オーディオ挙動が標準と異なる
- 視覚的レイアウトに異常な特徴が含まれる
- ロックドアインジケーターが見える
- squad 分離リスクが上昇している

これらのルームには、自動的な応答ではなく積極的な評価が必要です。ベテランは Tier C ルームをコミットする前に5〜10秒かけて評価します。

## Tier D: リスクのある通路

Tier D ルームは、特定の危険特性を持つため、リスクが高くなります。準備なしに入ると、escape オプションが悪い状態で Clark 遭遇につながる可能性があります。

**Tier D ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| 狭い通路 | きつい通路、限られた動き | 最後の手段、推奨されない |
| 1つの出口を持つL字型 | 2つのセグメント、1つの復帰点 | 他の選択肢がない場合のみ使用 |
| オーディオ異常付きT字ジャンクション | エコー挙動を持つ3方向 | まずオーディオで調査 |

**Tier D ルームのリスク:**

- チェイス中の限定された脱出オプション
- オーディオ挙動が標準と異なる可能性がある
- Clark があなたを簡単にコーナーに追い込める
- squad フォーメーション維持がより困難になる

これらのルームは慎重に入り、ナビゲーションパスがそれを必要とする場合にのみ入るべきです。新しいプレイヤーは反射的に Tier D ルームに入り、後悔することがよくあります。

## Tier F: 回避ゾーン

Tier F ルームは、最小限の戦術的価値と高い危険性を提供するため、可能な限り回避すべきです。時々入る必要はありますが、決して好まれません。

**Tier F ルームタイプ:**

| ルームタイプ | 特徴 | 最適な用途 |
|-----------|-----------------|----------|
| 行き止まり | 戻る以外の出口がない | 即座に引き返す |
| 閉じたドアのある通路 | ドアがそれ以上の通行をブロックする | 引き返す |
| 障害物のある単一方向 | パスがブロックされている | 別のルートを見つける |

**Tier F ルームの認識:**

- 2番目の出口が見えない
- ドアインジケーターがロックされていることを示している
- オーディオ挙動が密閉空間を示唆している
- 視覚的キューがブロックを示している

入る前に Tier F ルームを認識することで時間を節約できます。新しいプレイヤーは行き止まりをループだと思って歩いて入り、Clark が近づく中引き返さなければなりません。

## ルームタイプのオーディオ識別

各ルームタイプには、ベテランが入室前にルームを識別するために使用する独特のオーディオ signature があります。識別は1秒以内に発生します。

**ルームタイプのオーディオ signature:**

| ルームタイプ | オーディオ Signature |
|-----------|-----------------|
| ハブルーム | 複数のエコーソース、大きな環境音 |
| 長い通路 | 単一方向エコー、低い環境音 |
| オープルーム | エコーラップ、エアベントハム |
| 行き止まり | こもったエコーなし |
| T字ジャンクション | 2つの方向エコー |
| 曲線通路 | 方向シフトを伴うエコー |
| クロスジャンクション | 4方向エコー |

オーディオ識別には stereo headphones と訓練されたリスニングが必要です。ベテランはオーディオのみでルームタイプを識別します。これは flashlight battery が critical な場合に便利です。

## ルームタイプの頻度

procedural generator は各ルームタイプに異なる頻度を使用します。頻度を知ることで、次に何に遭遇するかを予測できます。

**ルームタイプの生成頻度:**

| ルームタイプ | 頻度 | メモ |
|-----------|-----------|-------|
| 標準イエロー通路 | 40% | 最も一般的 |
| 長い直線ホール | 20% | 2番目に一般的 |
| T字ジャンクション | 15% | 一般的 |
| L字ジャンクション | 10% | 一般的 |
| 曲線通路 | 5% | あまり一般的でない |
| ハブルーム | 3% | まれ |
| クロスジャンクション | 3% | まれ |
| オープルーム | 2% | まれ |
| 狭い通路 | 1% | 非常にまれ |
| 1つの出口を持つL字型 | 0.5% | 非常にまれ |
| ロックドア付きジャンクション | 0.3% | 非常にまれ |
| 行き止まり | 0.2% | 極めてまれ |

頻度データは、何百ものランにわたる community observation に基づいています。概算ですが、予測に役立ちます。

## ランフェーズごとのルーム選好

ランフェーズが異なると、さまざまなルームタイプのメリットがあります。以下の選好マトリックスは、各フェーズで優先するルームタイプを示しています。

**ランフェーズ別ルームタイプ選好:**

| ルームタイプ | ロビーフェーズ | 序盤 | 中盤 | 終盤 |
|-----------|-------------|------------|----------|-----------|
| ハブルーム | 高 | 高 | 中 | 低(発見を避ける) |
| T字ジャンクション | 中 | 高 | 高 | 中 |
| 標準通路 | 高 | 高 | 中 | 低 |
| 長い通路 | 低 | 中 | 高 | 高(距離を作る) |
| オープルーム | 低 | 中 | 中 | 高(visibility) |
| 行き止まり | 回避 | 回避 | 回避 | 回避 |
| 曲線通路 | 中 | 中 | 高 | 高(オーディオブレイク) |

優先順位が探索(ロビー、序盤)から survival(中盤)、脱出(終盤)にシフトするため、マトリックスは変化します。

## よくある質問

**Clark Huss rooms で最もまれなルームタイプは何ですか?**

行き止まりは生成頻度約 0.2% で最もまれです。見つけた場合、それは本当に異常です。

**Clark チェイス中、どのルームタイプが最も安全ですか?**

曲線通路と L字ジャンクションは、オーディオ line-of-sight を遮るため最適です。長い直線ホールは Clark がまっすぐ chase できるため最も悪いです。

**flashlight なしでルームタイプを識別できますか?**

はい、オーディオ識別は flashlight なしでも機能します。ベテランは low-battery フェーズ中にオーディオを頼りにします。

**Tier S ルームを見つけたら優先すべきですか?**

はい、ただし短時間だけです。Tier S ルームは再集合と空間マッピングに価値がありますが、長居には向いていません。30秒過ごして移動してください。

**将来のアップデートで tier リストはどう変わりますか?**

開発者が procedural generation を拡張するにつれて、tier リストには新しいルームタイプが含まれる可能性があります。フレームワークは追加に対応するように設計されています。

ルームタイプを使用するナビゲーション技術の詳細については、[huss rooms レイアウトガイド](/en/map/huss-rooms-layout/)を参照してください。Tier A ルームを使用する escape tactics を学ぶには、[Clark からの脱出](/en/guides/escaping-clark/)をお読みください。


**tier ランキングをどれくらいの頻度で再評価すべきですか?**

tier ランキングは、メジャーパッチ後と安定期間中は四半期ごとに再評価する必要があります。戦略の有効性はゲームの変更とともに変化します。ベテランは tier ランキングを時間の経過とともに追跡し、プレイスタイルを調整します。個人の tier ランキングは community consensus とは異なる場合があります。

**tier ランキングは普遍的ですか、それともプラットフォーム固有ですか?**

tier ランキングにはプラットフォーム固有のバリエーションがあります。PC プレイヤーはオーディオ依存戦略で利点があります。モバイルプレイヤーは、コントロールとオーディオ品質の違いにより、異なるアプローチを好む場合があります。tier ランキングをプレイに適用する際は、プラットフォームを考慮してください。

**独自の tier ランキングを作成するにはどうすればよいですか?**

複数のランでさまざまな戦略で自分のパフォーマンスを追跡します。成功率、生存時間、楽しさを記録します。個人データと community consensus を組み合わせて、独自のランキングを形成します。経験とゲームが進化するにつれてランキングを更新します。

**tier ランキングは戦略選択に影響を与えるべきですか?**

tier ランキングは戦略選択に関する情報となりますが、決定付けるべきではありません。個人の好みとプレイスタイルが有効性と同様に重要です。プレイスタイルに合わないわずかに弱い戦略よりも、あなたの長所に合うわずかに弱い戦略の方が優れたパフォーマンスを発揮する場合があります。ランキングを個人的な要素とバランスさせてください。

**tier ランキングと meta の違いは何ですか?**

tier ランキングは個々の戦略を孤立して評価します。meta は、支配的な組み合わせ、カウンター戦略、バランスシフトを含む全体的な戦略 landscape を記述します。両方ともゲーム状態を理解するために役立ちます。meta 分析は、コンポーネントとして tier ランキングを参照することがよくあります。

**squad 戦略は tier ランキングにどのように影響しますか?**

squad 戦略は、調整が効果を増幅するため、solo 戦略よりもランクが高くなることがよくあります。solo 戦略は solo プレイコンテキストでより高くランクされます。tier ランキングを評価する際は、戦略が solo 用か squad 用かを検討してください。一部の戦略は1つのコンテキストでのみ機能します。

**tier ランキングは間違っている可能性がありますか?**

tier ランキングは観察に基づく community consensus であり、絶対的な真実ではありません。個々の経験は consensus とは異なる場合があります。より低くランクされているいくつかの戦略は、特定のプレイヤーに対してより効果的に機能する場合があります。tier ランキングをガイダンスとして使用し、絶対的な規則として使用しないでください。
