Clark Hussルームでの役割分担は、ナビゲーション、脅威検出、フラッシュライト管理の認知負荷を部隊メンバー全体で分散する。役割が割り当てられていないと、全プレイヤーがリードしようとし、誰も耳を傾けず、最初 Clark に遭遇した時に部隊が分裂する。役割が割り当てられると、各プレイヤーは自分の責任を把握し、自分の特定の貢献に集中できる。

このガイドでは、3つのコア役割を詳細に説明し、各役割のスキル要件、疲労を防ぐためのローテーションシステム、部隊構成戦略を取り上げる。また、プレイヤーの強みに役割を合わせる方法、役割の失敗を処理する方法、責任をローテーションするタイミングについても学ぶ。

## 3つのコア役割

すべての連携された部隊は3つのコア役割を使用する。役割はリード（ナビゲーション）、リアガード（音声監視）、ライトマネージャー（フラッシュライト制御）である。

### **役割の定義:**

| 役割 | 主機能 | 副機能 |
|------|--------|--------|
| リード | ナビゲーションと経路選択 | 空間記憶管理 |
| リアガード | Clarkの音声監視 | 部隊の分離防止 |
| ライトマネージャー | フラッシュライトのタイミングとバッテリー | 視覚的調整 |

役割は実行中に交換できない。それぞれ異なるスキルとメンタルモデルを必要とする。

## リード役割の詳細

リードは部隊の最前列を歩き、どの通路に入るかを選択する。リードの決定は時間とともに蓄積され、誤った決定は部隊に時間とバッテリーを犠牲にさせる。

### **リードの責任:**

| 責任 | 説明 |
|------|------|
| 経路選択 | 分岐点で枝を選ぶ |
| 空間マッピング | 通路のメンタルマップを構築 |
| 部隊とのコミュニケーション | 今後の決定を通知 |
| ペース設定 | 音声監視のために歩行ペースを制御 |
| 脱出経路計画 | 撤退経路を事前に特定 |

### **リードのスキル要件:**

| スキル | 重要性 |
|--------|--------|
| 空間記憶 | 非常に高い |
| 意思決定の自信 | 高い |
| 忍耐力 | 高い |
| 経路効率 | 高い |
| 部隊管理 | 中程度 |

リード役割は、ナビゲーションを楽しみ、強い視覚的空間記憶を持つプレイヤーに適している。

## リアガード役割の詳細

リアガードは部隊の最後尾を歩き、Clarkの音声手がかりを監視する。リアガードのコールアウトは、部隊が準備するための早期警戒を提供する。

### **リアガードの責任:**

| 責任 | 説明 |
|------|------|
| 音声監視 | Clarkの音声手がかりを聞く |
| コールアウト実行 | Clarkの位置と距離を通知 |
| 分離防止 | 部隊の間隔を監視 |
| 脅威評価 | Clarkの行動状態を判断 |
| 追跡調整 | アクティブな追跡中にコールアウト |

**リアガードのスキル要件:**

| スキル | 重要性 |
|--------|--------|
| 音声解釈 | 非常に高い |
| 圧力下での冷静さ | 高い |
| コールアウトの速さ | 高い |
| 空間認識 | 高い |
| 忍耐力 | 中程度 |

リアガード役割は、強い音声解釈スキルと追跡中に冷静さを保つ能力を持つプレイヤーに適している。

## ライトマネージャー役割の詳細

ライトマネージャーは部隊の中間を歩き、フラッシュライトのタイミングを制御する。ライトマネージャーのクリックは、バッテリーを無駄にせずに視覚的確認の窓を提供する。

**ライトマネージャーの責任:**

| 責任 | 説明 |
|------|------|
| フラッシュライトのタイミング | 決定時点でクリック |
| バッテリー管理 | 残量を追跡 |
| 部隊との調整 | フォーメーションに合わせてクリック |
| しきい値決定 | バッテリーに基づいてモードを切り替え |
| ローテーション管理 | 必要時に役割を渡す |

**ライトマネージャーのスキル要件:**

| スキル | 重要性 |
|--------|--------|
| クリックの規律 | 非常に高い |
| タイミングの精度 | 高い |
| バッテリー認識 | 高い |
| 忍耐力 | 中程度 |
| 部隊認識 | 中程度 |

ライトマネージャー役割は、強い自己規律と持続的な慎重な行動への忍耐を持つプレイヤーに適している。

## プレイヤーの強みに役割を合わせる

効果的な役割分担は、各役割をプレイヤーの強みに合わせる。以下のマッチングマトリクスは部隊が役割を割り当てるのに役立つ。

**プレイヤーの強みから役割へのマッピング:**

| プレイヤーの強み | 最適な役割 |
|-----------------|-----------|
| 強い空間記憶 | リード |
| 優れた音声解釈 | リアガード |
| 忍耐強く規律的 | ライトマネージャー |
| 圧力下で冷静 | リアガードまたはリード |
| 細部に強い | ライトマネージャー |
| 決定的な瞬間で果断 | リード |
| 一貫して安定 | ライトマネージャー |

このマッピングにより、各プレイヤーが自然な強みを活かす役割に配置される。

## 役割ローテーションシステム

持続的な役割の責任は疲労を引き起こす。部隊はエラーを防ぐために役割をローテーションすべきである。ローテーションシステムは部隊のサイズによって異なる。

**ローテーション間隔:**

| 部隊サイズ | 推奨間隔 |
|------------|----------|
| デュオ | 5分 |
| トリオ | 4分 |
| クアトロ | 3分 |

ローテーション中、現在のライトマネージャーは次のプレイヤーに渡し、リードとリアガードが交代する、というように続く。ローテーションはコールアウトで通知される。

## 部隊構成の考慮事項

部隊構成は各プレイヤーがどの役割を取るかに影響する。以下の構成パターンは機能することが証明されている。

**効果的な構成:**

| 構成 | 強み |
|------|------|
| 3人のベテラン | 最大限の調整 |
| 2人のベテラン + 1人の学習者 | バックアップ付きの学習 |
| 混合経験 | 多様な視点 |
| 全員学習者 | より高い難易度、より良い学習 |

構成は役割の割り当てに影響する。ベテランペアがリードとリアガードを引き受け、学習者がライトマネージャーになってクリックの規律を養うことができる。

## 役割失敗の処理

役割保持者が失敗した場合、部隊は迅速に対応しなければならない。以下の失敗処理プロトコルは影響を最小限に抑える。

**失敗処理:**

| 失敗 | 対応 |
|------|------|
| リードが間違った方向に進む | 新しいリードを指名し、引き返す |
| リアガードがコールアウトを逃す | 他の部隊メンバーが補う |
| ライトマネージャーがクリックを使いすぎる | 別のプレイヤーに渡す |
| 複数の失敗 | 部隊が一時停止し、再集合し、再評価する |

鍵は迅速な認識と即座の対応である。遅延は失敗を悪化させる。

## 複数役割能力

一部の経験豊富なプレイヤーは同時に複数の役割を保持できる。これは1人のプレイヤーがリードとライトマネージャーをカバーするデュオプレイで便利である。

**複数役割構成:**

| 構成 | 組み合わせ役割 |
|------|----------------|
| デュオ: プレイヤーA | リード + ライトマネージャー |
| デュオ: プレイヤーB | リアガード + フォロワー |
| クアトロ: プレイヤーA | リード |
| クアトロ: プレイヤーB | リアガード |
| クアトロ: プレイヤーC | ライトマネージャー |
| クアトロ: プレイヤーD | フォロワー + バックアップ |

複数役割能力は練習を通じて発達する。新しいプレイヤーはまず単一の役割に集中すべきである。

## 役割別の準備

各役割はランの開始前に特定の準備を必要とする。以下の準備手順により各プレイヤーの準備が整う。

**リードの準備:**

- ロビーのマップをざっと確認
- 有望な初期方向を特定
- 脱出経路のオプションを計画
- ペース設定戦略を確認

**リアガードの準備:**

- オーディオ音量レベルを設定
- 呼吸のケイデンス識別を練習
- 必要に応じて冷静な声のバックアップを特定
- コールアウト形式を確認

**ライトマネージャーの準備:**

- バッテリーが緑であることを確認
- クリックパターンの習慣を設定
- ローテーションのタイミングを特定
- モード切り替えのしきい値を確認

準備には30秒かかり、ほとんどの役割の失敗を防ぐ。

## 役割のシナジーパターン

役割間のシナジーが部隊を効果的にする。以下のシナジーパターンは連携プレイで観察される。

**リード-リアガードのシナジー:**

| パターン | 効果 |
|---------|------|
| リアガードがClarkの接近をコール | リードが脱出経路を選択 |
| リードが方向を通知 | リアガードが新しい角度から報告 |
| 両者が音声観察を共有 | 包括的な脅威の全体像 |

**ライトマネージャー-リアガードのシナジー:**

| パターン | 効果 |
|---------|------|
| リアガードが静かな窓を報告 | ライトマネージャーが確認のためにクリック |
| ライトマネージャーが追跡中に節約 | リアガードが音声に集中 |
| 両者がクリックに合わせてコールアウトをタイミング | 最大限の情報収集 |

**リード-ライトマネージャーのシナジー:**

| パターン | 効果 |
|---------|------|
| リードが分岐点接近の合図 | ライトマネージャーがプレビューにクリック |
| ライトマネージャーがバッテリーを報告 | リードが低照度エリアのために経路を調整 |
| 両者が入場タイミングを調整 | クリーンな部屋への入場 |

強いシナジーは同じ部隊との一貫したプレイを通じて発達する。

## 役割ローテーションのベストプラクティス

役割のローテーションはスムーズで予測可能であるべきである。以下のベストプラクティスはローテーションが調整を妨げないことを保証する。

**ローテーションのベストプラクティス:**

| プラクティス | 説明 |
|-------------|------|
| ローテーションを早期に通知 | 「30秒でライトを渡す」 |
| 短い引き継ぎのオーバーラップ | 現在と次の役割保持者が短期間一緒に作業 |
| 静止中のローテーション | 安全な通路で一時停止してローテーション |
| 明確な引き継ぎ言葉 | 「今、ライトはあなたの責任」 |
| ローテーションを記録 | 新しいプレイヤーは観察して学ぶ |

最良のローテーションは実行中に気づかれない。

## よくある質問

**どの役割が最も重要ですか？**

リアガードが最も重要である。なぜなら彼らのコールアウトは突然の追跡を防ぐからである。平凡なナビゲーションを持つ良いリアガードは、劣悪な音声監視を持つ偉大なリードを上回る。

**1人のプレイヤーが3つの役割すべてを保持できますか？**

ソロプレイでのみ可能である。部隊では、役割の組み合わせは認知過負荷を引き起こし、各役割の effectivenessを低下させる。

**弱い役割をどうやって発達させますか？**

ソロセッションまたはフィードバックを提供できる友人と弱い役割を練習する。役割の発達には意図的な練習が必要である。

**誰も特定の役割を望まない場合はどうしますか？**

プレイヤーの強みに基づいて割り当てる。最も望まれない役割はしばしばライトマネージャーだが、部隊のフラッシュライト保全に不可欠である。

**役割はラン全体で固定されるべきですか？**

いいえ。ローテーションは疲労を防ぐ。固定された役割はプレイヤーが疲れるにつれてエラーを引き起こす。

調整を必要とする役割メカニクスの詳細については、[協力サバイバルガイド](/en/multiplayer/co-op-survival-guide/)を参照してください。より広範な調整原則を学ぶには、[マルチプレイヤー調整](/en/guides/multiplayer-coordination/)を読んでください。

**有害な部隊メイトをどのように処理しますか？**

有害なプレイヤーをすぐにミュートする。ポジティブな部隊メイトとの調整に集中する。部隊全体が有害な場合は、ロビーを離れてより良いプレイヤーを探す。コミュニティチャンネルを通じた長期的な部隊構築は、ランダムな有害な行動への露出を減らす。

**部隊が戦略について意見が合わない場合はどうしますか？**

ゲーム前の戦略合意は、ラン中の衝突を防ぐ。プレイ中に意見の相違が生じた場合は、割り当てられたリードに従う。ラン後の議論で戦略の問題を建設的に対処できる。即座の失敗に直面している場合を除き、ランの途中で戦略を変更することは避ける。

**時間とともに部隊としてどのように改善しますか？**

一緒に定期的にプレイすることで調整習慣が築かれる。失敗したランをレビューして改善エリアを特定する。追跡やバッテリー管理などの特定のシナリオを練習する。役割をローテーションして多才な部隊メンバーを育成する。複数のセッションにわたって進捗を追跡する。

**RobloxボイスチャットとDiscordのどちらを使用すべきですか？**

Discordは一般にRobloxボイスチャットよりも優れた音声品質とより多くの機能を提供する。Discordはプッシュトーク、ノイズ抑制、チャンネル分離をサポートしている。Robloxボイスは便利だが信頼性が低い。ほとんどの連携された部隊はDiscordを好む。

**カオスなロビーでコミュニケーションする最良の方法は何ですか？**

標準化されたコールアウトを使用し、延長された議論を避ける。プッシュトークの規律が音声の乱雑さを防ぐ。冷静な声の指定がコミュニケーションを安定させるのに役立つ。カオスなプレイヤーをミュートして部隊に集中する。

**異なるタイムゾーンの友人とプレイできますか？**

タイムゾーンの違いにはスケジュールの柔軟性が必要である。一部の部隊は重複する時間帯にプレイすることで複数のタイムゾーンにまたがって調整する。他の部隊は地域のサブ部隊を形成する。あなたの特定の状況に合ったものを見つける。

**新しい部隊メイトとの信頼をどう構築しますか？**

信頼は一貫したプレイと信頼できるパフォーマンスを通じて築かれる。スケジュール通りに参加し、役割を果たし、明確にコミュニケーションする。ドラマを避け、ゲームプレイに集中する。信頼は複数のセッションにわたって自然に発達する。
