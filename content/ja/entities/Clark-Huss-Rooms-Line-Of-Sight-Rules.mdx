視線はClarkの追跡システムにおける視覚コンポーネントです。オーディオが主要な検知方法ですが、視線（LOS）は確立されるとClarkに正確なターゲティングを提供します。視線の幾何学、壁の厚さに関するルール、視覚追跡を破る角戦略を理解することが生存のために不可欠です。

このガイドでは、視線メカニクスを詳細に解説し、検知に影響する壁の厚さルール、逃走ルートの幾何学、Clarkの追跡を妨害する角戦略について説明します。また、視覚追跡の精度や視線に対するフラッシュライトの効果についても学びます。

## Clark Huss Roomsにおける視線の意味

視線（LOS）とは、Clarkがプロシージャル生成された通路の幾何学を通じてあなたのキャラクターモデルを見る能力のことです。LOSが確立されると、Clarkの追跡精度は劇的に向上します。

### **視線の状態：**

| 状態 | Clarkの追跡 | 対抗手段 |
|------|-------------|----------|
| 直接LOS | 高精度 | 即座にLOSを切る |
| 薄い壁越しのLOS | 精度低下 | 移動して切断 |
| 厚い壁越しのLOS | オーディオのみ | オーディオマスキング |
| LOS遮断 | オーディオのみ | オーディオマスキング |
| LOS不可能 | オーディオのみ | 通常ナビゲーション |

状態は、あなたとClarkが通路を移動するにつれて動的に変化します。

## 壁の厚さメカニクス

壁の厚さは光や場合によっては音がどれだけ透過するかに影響します。Clarkの視覚検知は壁の厚さルールに従います。

### **壁の厚さの影響：**

| 厚さ | 光の透過 | 視覚LOS |
|------|----------|---------|
| 0（通路） | 完全 | あり |
| 1層 | 減少 | あり（薄暗い） |
| 2層 | なし | なし |
| 3層以上 | なし | なし |

照明ルールが存在するからこそ、フラッシュライトの使用は薄い壁越しにはあなたの位置を露出し、厚い壁越しには露出しません。

## 角戦略の基礎

角戦略はClark Huss roomsで視線を切る最も信頼性の高い方法です。この戦略は通路の曲がり角の幾何学を利用します。

### **角戦略の原則：**

| 原則 | 説明 |
|------|------|
| 各角でLOSが切れる | 急角度のターンで追跡が妨害される |
| 連続する角は複合効果 | 複数の角が信頼性を追加 |
| 直角が最も効果的 | 90度のターンが最も有効 |
| 広い角は効果低い | 緩やかなカーブは効果が弱い |
| 行き止まりは不利 | 切断を継続できない |

ベテラープレイヤーは逃走ルートで複数の連続する角を使用します。なぜなら、各角が追跡妨害時間を追加するからです。

## 視覚検知範囲

Clarkの視覚検知範囲はオーディオ範囲よりも短いです。視覚検知は近距離で最も有用です。

### **視覚検知範囲：**

| 障害物 | 範囲 |
|--------|------|
| 直線 | 10〜15メートル |
| 角を曲がった先 | 0〜3メートル |
| 薄い壁越し | 2〜5メートル |
| 厚い壁越し | 0メートル |

視覚範囲はオーディオ範囲よりも大幅に短いため、オーディオが主要な検知方法となっています。

## 視線に対するフラッシュライトの効果

フラッシュライトの使用は視線に対して特定の効果をもたらします。効果の理解はフラッシュライトの戦略的使用に役立ちます。

**フラッシュライトの効果：**

| フラッシュライト状態 | 視線への影響 |
|----------------------|--------------|
| オフ | 通常のClark検知 |
| シングルクリック | 短時間の照明、最小限の効果 |
| 持続照射 | Clarkが薄い壁越しにあなたを見える |
| 点滅 | 混乱効果、検知ブレイクの可能性 |

持続的なフラッシュライト使用は視線にとって最悪のケースです。なぜなら、障壁越しにClarkに視覚的確認を与えるからです。

## 逃走の幾何学

通路の幾何学は逃走が可能かどうかを決定します。最適な逃走幾何学には複数の角と限られた行き止まりが含まれます。

**逃走幾何学の構成要素：**

| 構成要素 | 重要性 |
|----------|--------|
| 角の密度 | 高（角が多い=良好） |
| T字路 | 高（複数の選択肢） |
| 開放的な部屋 | 低（露出） |
| 長い直線通路 | 低（予測可能） |
| 行き止まり | 非常に低（避ける） |

ベテランは角の密度を最大化し、露出を最小限に抑える逃走ルートを選択します。

## 角ブレイクテクニック

角ブレイクテクニックはClarkの視線から逃れる最も信頼性の高い方法です。このテクニックは幾何学とタイミングを利用します。

**角ブレイクの実行：**

| ステップ | アクション |
|----------|-----------|
| 1 | 前方の逃走角を特定 |
| 2 | 角に向かってスプリント |
| 3 | 角で急ターン |
| 4 | 3〜5秒間継続 |
| 5 | LOSが切れたか確認 |
| 6 | 次の角へ進む |

各角ブレイクの実行には5〜10秒かかります。複数の連続ブレイクが信頼性を追加します。

## スタックドコーナー戦略

スタックドコーナーとは、視線ブレイクを複合させる複数の連続する90度ターンのことです。この戦略は非常に信頼性が高いです。

**スタックドコーナーの利点：**

| 利点 | 説明 |
|------|------|
| LOSブレイクの複合 | 各角が3秒の妨害を追加 |
| オーディオトレイルの混乱 | 方向転換がオーディオ追跡を乱す |
| 複数の逃走オプション | 各角が新しい方向を提供 |
| 高い生存確率 | 2つの角で80%以上の成功率 |

ベテランスプレイヤーは、Clarkが積極的に追跡している際の確実な逃走のためにスタックドコーナーを使用します。

## 通路の壁の現象

壁の現象には、通路の幾何学に特化した視覚的および音響的な効果が含まれます。これらの現象は検知とナビゲーションに影響します。

**壁の現象：**

| 現象 | 効果 |
|------|------|
| 薄い壁のフラッシュライト | Clarkが壁越しに見える |
| エコー反射 | オーディオが反射し、知覚が変化 |
| ドアプレビュー | ドアインジケーターがフレーム越しに見える |
| 装飾壁 | 視覚的に区別される、機能的効果なし |
| 強化壁 | 透過しない、ゲームプレイ効果あり |

特定の通路が他の通路よりも危険に感じるのはこれらの現象があるためです。

## 視覚追跡精度

視覚追跡精度は距離、照明、プレイヤーの動きに基づいて変化します。精度はClarkがあなたを追跡する信頼性に影響します。

**視覚追跡精度：**

| 条件 | 精度 |
|------|------|
| 直接LOS、近距離 | 非常に高い |
| 直接LOS、中距離 | 高い |
| 直接LOS、遠距離 | 中程度 |
| 薄い壁越し | 低い |
| 厚い壁越し | なし |

精度は、Clarkがあなたを見た後にどの程度自信を持って追跡できるかを決定します。

角ブレイク以外にも、視線を切るテクニックがあります。以下のテクニックは特定の状況で機能します。

**LoSブレイクテクニック：**

これらのテクニックは状況依存であり、角ブレイクほど信頼性はありません。

## LoSとサーバーロック

サーバーロックはClarkの検知を増加させることにより視線に影響します。ロック状態とLoSの関係は微妙です。

**サーバーロックLoS効果：**

| 状態 | LoS効果 |
|------|---------|
| ロック前 | 標準LoSルール |
| ロック直後 | LoS範囲がわずかに増加 |
| ゲーム中盤 | 持続検知が増加 |
| ゲーム終盤 | ClarkのLoS追跡がより積極的 |

これらの効果はオーディオ感度ブーストと積み重なり、ゲーム終盤のより危険な環境を作り出します。

## よくあるLoSのミス

プレイヤーは視線に関連して特定のミスを犯します。ミスを特定することは防止に役立ちます。

**よくあるミス：**

| ミス | 影響 |
|------|------|
| 長い直線の逃走経路 | 予測可能、追跡が容易 |
| 単一角の逃走 | アクティブな追跡には不十分 |
| 開放的な部屋への逃走 | 最大の露出 |
| 追跡中にフラッシュライトを点灯し続ける | Clarkに対する最大の可視性 |
| 角で停止する | 再捕捉を許す |

これらのミスを避けることで、逃走の成功率が大幅に向上します。


**クイック検知リファレンス：**

- 心拍は即座の脅威なしでClarkが遠距離で巡回していることを示す
- 呼吸のケイデンスが近接性と警戒レベルを明らかにする
- 足音のドスンドスンはClarkが隣接する部屋にいることを示唆する
- ささやきの断片は高い警戒と差し迫ったエスカレーションを示す
- スプリントバーストは全速力での後退が必要なアクティブチェイスを示す
- ボーカライゼーションはClarkが近く、あなたの位置を検知していることを意味する

**対抗戦略の基礎：**

- 静かに歩くことでオーディオフットプリントが大幅に減少する
- フラッシュライトのクリック規律がバッテリーを延ばし、検知範囲を保つ
- 角ブレイクが追跡開始時に視覚追跡を妨害する
- 10秒以上の持続的な沈黙がClarkのオーディオトレイルを失わせる
- 部隊移動の同期が単一ターゲット追跡を混乱させる
- バッテリー閾値規律が緊急消耗状況を防ぐ


## よくある質問

**角ブレイクはアクティブな追跡に対してどの程度効果的ですか？**

単一角ブレイクは約50%の成功率です。2つの連続ブレイクは80%以上の成功率です。3つのブレイクはほぼ確実です。

**Clarkは複数の壁越しに見ることができますか？**

いいえ。Clarkの視覚検知は2つの壁層で停止します。オーディオは継続しますが、視覚はブロックされます。

**自分のフラッシュライトは自分のLoS可視性に影響しますか？**

はい。あなたのフラッシュライトは壁を照らし、薄い壁越しにあなたのシルエットを露出させる可能性があります。クリック規律がこの効果を減らします。

**逃走に最適な部屋の幾何学は何ですか？**

複数のターンを含むL字型の通路が最善です。開放的な部屋は360度の完全な視認性を提供するため最悪です。

**装飾の背後に隠れるとLoSが切れますか？**

はい、装飾オブジェクトはLoSをブロックします。ただし、Clarkは視覚接触を再確立するためにそれらを迂回する可能性があります。

オーディオ追跡の詳細については、[オーディオ追跡解説ガイド](/en/entities/audio-tracking-explained/)を参照してください。逃走戦術を詳しく学ぶには、[Clarkからの逃走](/en/guides/escaping-clark/)をお読みください。


**Clarkは将来のアップデートで大幅な変更を受けますか？**

ClarkはEarly Accessを通じてバランス調整を受ける可能性があります。開発者はコミュニティフィードバックを監視し、適切な難易度を維持するためにClarkの挙動を調整します。大きな変更はパッチノートを通じて発表されます。ベテランスプレイヤーはClarkのメカニクスの定期的な調整に備えるべきです。

**Clark遭遇シナリオをどのように練習しますか？**

コミュニティのオーディオツールが練習用の分離されたClarkオーディオテルを提供します。低圧力のシナリオでのゲーム内練習がスキルを構築します。ソロランは調整の複雑さなしにClarkの集中したインタラクションを可能にします。ベトランプレイヤーは特定のシナリオを繰り返し練習して自動的な反応を構築します。

**Clarkのさまざまな状態の違いは何ですか？**

Clarkは巡回、偵察、追跡、追求、チェイス、クールダウン状態を通過します。各状態には異なるオーディオキュー、検知範囲、行動パターンがあります。状態遷移を理解することでClarkの次のアクションを予測できます。ベテランスプレイヤーはオーディオモニタリングを通じて状態変化を追跡します。

**部隊でClarkのターゲティングを混乱させることができますか？**

はい、部隊プレイは協調的なオーディオマスキングを通じてClarkのターゲティングを混乱させることができます。複数のプレイヤーが一緒に移動することで重複するオーディオシグネチャが作成されます。指定されたディストラクターが脆弱な部隊員からClarkの注意を引き離すことができます。部隊の調整はソロプレイよりも多くの混乱の機会を提供します。

**フラッシュライトの使用はClarkの検知にどのように影響しますか？**

持続的なフラッシュライトの使用はClarkの検知範囲を大幅に増加させます。クリック規律は視覚情報を提供しながらこの効果を最小限に抑えます。オーディオのみのナビゲーションはフラッシュライト関連の検知を完全に除去します。バッテリー状態とClarkの近接性に基づいてフラッシュライト戦略を選択してください。

**Clarkの弱点は何ですか？**

Clarkの主な弱点には、オーディオの沈黙、角ブレイク逃走、部隊の混乱が含まれます。オーディオ出力を最小限に抑えるプレイヤーは追跡が困難です。急角度の角ブレイクが視覚追跡を妨害します。部隊は単一ターゲット追跡を混乱させる複数のオーディオシグネチャを作成します。これらの弱点を一貫して活用してください。

**Clarkは他のホラーゲームのモンスターとどのように比較されますか？**

Clarkは忍耐強いストーカー＝リスナーデザインを通じて典型的なホラーゲームのモンスターとは異なります。彼は多くのホラーゲームのモンスターほど即座に攻撃的ではありませんが、より持続的です。彼のオーディオ重視の追跡は、隠れるメカニクスよりも規律あるプレイを報います。このデザインはユニークな緊張感を生み出します。
