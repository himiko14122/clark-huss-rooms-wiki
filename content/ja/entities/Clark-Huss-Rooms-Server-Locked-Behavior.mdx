Clark Huss rooms のサーバーロックはクラークの挙動を特定の方法で変化させます。ロックは主に新規プレイヤーの参加を防止しますが、同時にクラークのオーディオ感度、パトロールパターン、エスカレーションルールも変更します。これらの変化を理解することで、ロック発動後に戦略を適応させることができます。

このガイドでは、サーバーロック後のクラークの具体的な挙動変化、これらの変化のタイミング、累積的な感度効果、そしてベテランプレイヤーが使用する戦略調整について解説します。終盤の難易度カーブとポストロックプレイの具体的なサバイバル技術についても学習できます。

## サーバーロック後に何が起こるか

サーバーロックが発動すると、クラークの挙動は測定可能な方法で変化します。これらの変化はランの進行に応じて緊張感を高めるように設計されています。

### **ポストロック変化：**

| 変化 | 効果 | タイミング |
|--------|--------|--------|
| オーディオ感度ブースト | 検知範囲 +15% | 即時 |
| パトロール再配置 | ロビーに接近 | 30〜60秒 |
| クールダウン時間短縮 | 回復時間が減少 | 即時 |
| エスカレーションタイミング短縮 | 状態変化が高速化 | 累積的 |
| スポーン密度増加 | エンカウント頻度上昇 | 2〜3分 |

これらの変化は時間とともに蓄積し、段階的に危険な環境を形成します。

## オーディオ感度ブースト

オーディオ感度ブーストはポストロックで最も重要な変化です。クラークはより遠くから、より少ない労力でプレイヤーを検知します。

### **感度ブーストの詳細：**

| 音の種類 | ロック前範囲 | ロック後範囲 | 増加率 |
|------------|----------------|------------------|----------|
| 歩行 footstep | 5メートル | 5.75メートル | +15% |
| ダッシュ | 12メートル | 13.8メートル | +15% |
| フラッシュライト click | 6メートル | 6.9メートル | +15% |
| フラッシュライト持続 | 18メートル | 20.7メートル | +15% |
| ボイスチャット | 可変 | 検知 +15% | +15% |
| 衝突音 | 15メートル | 17.25メートル | +15% |

15%のブーストは他の感度修正と積み重なり、終盤の満員ロビーでは極めて検知重視の環境になります。

## パトロール再配置

サーバーロック後、クラークのパトロールパターンが変化します。クラークはロビーエリアに近づき、より積極的にパトロールします。

### **パトロール再配置フェーズ：**

| フェーズ | ロック経過時間 | クラークの位置 |
|-------|------------------|-----------------|
| 初期 | 0〜30秒 | 遠距離、心音のみ |
| 早期 | 30〜90秒 | 中距離、時折呼吸音 |
| 中期 | 90秒〜3分 | ロビーに接近、頻繁な手がかり |
| 後期 | 3分以上 | 攻撃的なポジショニング |

再配置により圧力勾配が生まれ、プレイヤー予想より早くエンカウントが発生します。

## クールダウン時間短縮

サーバーロック後、クラークのクールダウン時間が短縮されます。標準の30秒クールダウンが20秒以下に減少する可能性があります。

### **クールダウン短縮：**

| ロック状態 | クールダウン時間 |
|------------|-------------------|
| ロック前 | 30〜45秒 |
| ロック直後 | 25〜35秒 |
| ロック中期 | 20〜30秒 |
| ロック後期 | 15〜25秒 |

クールダウンが短縮されることで、フラッシュライト使用や再集合の安全時間が減少します。

## エスカレーションタイミングの変化

サーバーロック後、クラークの状態遷移が高速化されます。タイミングの変化は対応可能な時間に影響します。

**エスカレーションタイミング比較：**

| 遷移 | ロック前タイミング | ロック後タイミング |
|------------|------------------|---------------------|
| パトロール→調査 | 3〜5秒 | 2〜4秒 |
| 調査→追跡 | 5〜8秒 | 3〜6秒 |
| 追跡→追撃 | 5〜10秒 | 3〜7秒 |
| 追撃→チェイス | 3〜5秒 | 2〜4秒 |

遷移の高速化により対応ウィンドウが縮小します。ベテランはロック後により迅速に対応します。

## スポーン密度増加

サーバーロック後、クラークのエンカウント頻度が増加します。増加は漸次的ですが累積的です。

**エンカウント頻度：**

| ロック経過時間 | 1分あたりのエンカウント数 |
|------------------|------------------------|
| 0〜1分 | 1〜2 |

頻度の増加により、フラッシュライトバッテリーとスタミナがロック前より速く消耗します。

## ロック後の戦略調整

ベテランプレイヤーはクラークの挙動変化に対応するため、ロック後に戦略を調整します。以下の調整は重要です。

**ロック後の調整：**

| 調整 | 説明 |
|------------|-------------|
| フラッシュライト使用の削減 | 以前よりクリック重視 |

| 脱出ルートの早期確保 | 中盤前の計画 |

これらの調整はランの進行に応じてより積極的になります。

## ロック直後のサバイバル

ロック後の最初の3分間が決定的な重要性を持ちます。変化は即時ですが、プレイヤーはまだ適応していません。以下のサバイバル技術が役立ちます。

**ロック直後の技術：**

| 技術 | 説明 |
|-----------|-------------|
| 一時停止と方向確認 | ロック後最初の10秒 |
| 役割の確認 | スクワッドの調整を確保 |
| ライトマネージャー状態 | バッテリーが緑であることを確認 |
| 初期オーディオマップ構築 | 中盤前に重要 |
| 脱出ルートの特定 | 角ブレや行き止まりを記録 |

最初の3分間がラン全体のトーンを決定します。

## ロック中期のサバイバル

ロック中期フェーズ（3〜6分）はほとんどのランが失敗するフェーズです。累積的な感度ブーストにより、あらゆるミスの代償が大きくなります。

**ロック中期の技術：**

| バッテリー閾値の規律 | 30%以下はオーディオのみ |
| 継続的なオーディオ監視 | リッスンはノンストップ |

ロック中期のプレイには最大限の規律が必要です。

**ロック後期の技術：**

| 技術 | 説明 |

| フルステルス | オーディオ出力を最大限削減 |
| 脱出優先 | 探索より脱出口 |
| 役割統合 | 役割を必須に削減 |
| スタミナ reserve | チェイス時のみダッシュ |

ロック後期は探索ではなく生存が重要です。

## ロック前のフェーズでのポストロック準備

ポストロック挙動の最良の準備はロックが発動する前に行われます。以下のロック前準備ステップが役立ちます。

**ロック前の準備：**

| ステップ | 時間 | 目的 |
|------|------|---------|
| 1 | スクワッド役割の確認 | ポストロック調整 |
| 2 | 初期マップ構築 | ポストロック用リファレンス |
| 3 | フラッシュライトのテスト | バッテリー状態の確認 |
| 4 | 脱出ルートの計画 | ロック前の脱出オプション |
| 5 | calm voice の指定 | ポストロックのパニック制御 |

これらのステップは30秒で完了し、ポストロック生存率を劇的に改善します。


**クイック検知リファレンス：**

- 心音は即時脅威なしの遠距離パトロール中を示す
- 呼吸 cadenc eは近接性と警戒レベルを明らかにする
- Footstep thud はクラークが隣接部屋にいることを示唆する
- Whisper 断片は高い警戒と差し迫ったエスカレーションを示す
- ダッシュバーストは完全撤退が必要なアクティブチェイスの合図
- 発声はクラークが接近し位置を検知していることを意味する

**カウンター戦略の基本：**

- 静かに歩くことでオーディオフットプリントが大幅に減少する
- フラッシュライトの click 規律は検知範囲を維持しつつバッテリーを延ばす
- 角ブレは追跡開始時の視覚追跡を妨害する
- 10秒以上の持続的 silence はクラークのオーディオトレイルを失わせる
- スクワッド移動の同期は単体ターゲット追跡を混乱させる
- バッテリー閾値規律は緊急消耗状況を防ぐ


## よくある質問

**クラークの挙動が最も劇的に変化するのはいつですか？**

ロック発動後の最初の30秒で即時変化がトリガーされます。累積効果は次の5分以上にわたって構築されます。

**ロック効果を軽減できますか？**

いいえ。ロック効果はそのマッチでは永続的です。唯一の緩和策は累積曝露を減らすための高速ランです。

**最も危険なロック後の時間はいつですか？**

3〜5分のウィンドウが最も危険です。累積効果が蓄積されているものの、プレイヤーの疲労がまだピークに達していないためです。中盤が danger zone です。

**ロック中に戦略を変更すべきですか？**

はい。危険度レベルの上昇に伴い戦略調整は継続的です。ベテランは30〜60秒ごとにアプローチを更新します。

**長いポストロックランを生存することは可能ですか？**

はい、ただし最大限の規律とリソース管理が必要です。トッププレイヤーはポストロック技術への厳格な準拠で12分以上の生存を達成しています。

サーバーロックタイミング処理の戦略の詳細については、[server lock strategy guide](/en/guides/server-lock-strategy/) をご覧ください。より広範なクラーク挙動パターンを学ぶには、[Clark entity anatomy](/en/entities/clark-entity-anatomy/) をお読みください。


**クラークは将来のアップデートで大きな変更を受けますか？**

クラークは Early Access を通じてバランス調整を受ける可能性が高いです。開発者はコミュニティフィードバックを監視し、適切な難易度を維持するためにクラークの挙動を調整します。大きな変更はパッチノートを通じて発表されます。ベテランはクラークのメカニズムへの定期的な調整に備えるべきです。

**クラークのエンカウントシナリオを練習するにはどうすればよいですか？**

コミュニティオーディオツールが練習用の分離されたクラークオーディオテルを提供します。低圧力のシナリオでの ingame 練習がスキルを構築します。ソロランは調整の複雑さなしにクラークとの集中的な対話を可能にします。ベテランプレイヤーは自動応答を構築するために特定のシナリオを繰り返し練習します。

**クラークのさまざまな状態の違いは何ですか？**

クラークはパトロール、調査、追跡、追撃、チェイス、クールダウン状態を通って遷移します。各状態には distinct なオーディオキュー、検知範囲、挙動パターンがあります。状態遷移を理解することはクラークの次のアクションを予測するのに役立ちます。ベテランはオーディオ監視を通じて状態変化を追跡します。

**スクワッドでクラークのターゲティングを混乱させることができますか？**

はい、スクワッドプレイは調整されたオーディオマスキングを通じてクラークのターゲティングを混乱させることができます。複数プレイヤーが一緒に移動することで重複するオーディオシグネチャが作成されます。指定された distract or が脆弱な squadmate からクラークの注意を引き離すことができます。スクワッド調整はソロプレイより多くの混乱機会を提供します。

**フラッシュライト使用はクラークの検知にどのように影響しますか？**

持続的なフラッシュライト使用はクラークの検知範囲を大幅に増加させます。Click 規律は visual 情報を提供しつつこの効果を最小限に抑えます。オーディオのみのナビゲーションはフラッシュライト関連の検知を完全に除去します。バッテリー状態とクラークの近接性に基づいてフラッシュライト戦略を選択してください。

**クラークの弱点は何ですか？**

クラークの主な弱点にはオーディオ silence、角ブレ脱出、スクワッド混乱が含まれます。オーディオ出力を最小限にするプレイヤーは追跡が困難です。シャープな角ブレは視覚追跡を妨害します。スクワッドは単体ターゲット追跡を混乱させる複数のオーディオシグネチャを作成します。これらの弱点を一貫して exploit してください。

**クラークは他のホラーゲームのモンスターとどう違いますか？**

クラークは patient stalker-listener デザインにより典型的なホラーゲームモンスターとは異なります。多くのホラーゲームモンスターほど即時には aggressive ではありませんが、より persistent です。オーディオ重視の追跡は hiding メカニクスではなく規律あるプレイを reward します。このデザインは unique な緊張感を生み出します。
