**¿Puedo canjear códigos en móvil?**

Sí, pero la experiencia es más lenta que en PC debido a las limitaciones del teclado táctil. Usa copiar y pegar cuando sea posible.

Recibirás un mensaje de error indicando que el código es inválido. Vuelve a ingresar el código con cuidado, verificando cada carácter.

**¿Puedo canjear el mismo código dos veces?**

No. Cada código solo se puede canjear una vez por cuenta. Intentar canjear dos veces devuelve un error de "ya canjeado".

**¿Los códigos funcionan en todas las regiones?**

La mayoría de los códigos funcionan globalmente, pero algunos están bloqueados por región. Revisa la descripción del código para ver restricciones regionales.
