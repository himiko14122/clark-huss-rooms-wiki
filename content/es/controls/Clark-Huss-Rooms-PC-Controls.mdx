## Distribución Estándar del Teclado

La distribución estándar del teclado para Clark Huss rooms sigue el movimiento WASD con la linterna y la interacción en teclas adyacentes. La distribución es familiar para la mayoría de los jugadores de PC.

### **Distribución estándar:**

| Tecla | Función |
|-----|----------|
| W/A/S/D | Movimiento |
| Shift (izquierdo) | Correr |
| Espacio | Saltar (uso limitado) |
| Ctrl o C | Agacharse |
| F | Encender/apagar linterna |
| E | Interactuar |
| Q | Rueda de llamadas (si está disponible) |
| T | Pulsar para hablar |
| Tab | Inventario (si aplica) |
| Escape | Pausa |

La distribución coloca las teclas usadas frecuentemente cerca de las teclas de movimiento para un acceso fácil.

Cierra aplicaciones en segundo plano que puedan consumir recursos. Reduce los ajustes gráficos de Roblox si el rendimiento es inestable. Contacta al soporte de Roblox para problemas específicos de la plataforma que persistan.
